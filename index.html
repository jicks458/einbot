기능

필요한 것만, 알아서

복잡한 설정 없이 켜면 바로 일합니다. 문구 하나까지 내 방송에 맞게 바꿀 수 있어요.

🙋 출석 체크

"안녕하세요" 한마디면 자동 출석. 출석 횟수가 쌓여 단골 시청자가 보입니다. 다른 봇에서 넘어와도 횟수를 이어받을 수 있어요.

💝 후원·구독 감사 인사

치즈 후원, 구독, 구독권 선물까지 놓치지 않고 즉시 감사 인사를 올립니다. 문구는 내 마음대로.

🎲 명령어

!출첵, !팔로우, !업타임, !시간 기본 제공. 나만의 명령어와 반복 공지도 클릭 몇 번으로 추가됩니다.

🤖 우리 방송만의 봇 이름

모두가 똑같은 이름을 쓰는 봇이 아니에요. 부계정을 연결하면 내가 지은 "OO봇" 이름으로 응답합니다.

🖥️ 내 컴퓨터에서

봇은 내 컴퓨터에서 직접 돕니다. 로그인 정보와 시청자 기록은 내 PC에만 저장되고 외부로 보내지 않아요. (이용권 확인할 때만 인터넷을 씁니다)

🔔 알아서 챙김

새 버전 알림, 로그인 만료 안내까지 앱이 먼저 알려줍니다. 신경 쓸 게 없어요.

FAQ

자주 묻는 질문

컴퓨터를 잘 몰라도 쓸 수 있나요?

네. 설치하면 안내 화면이 순서대로 알려줍니다. 로그인 두 번이면 준비 끝이고, 어려운 부분은 그림 안내가 함께 나와요.

쓰려면 뭐가 필요한가요?

Windows PC와 치지직 계정이면 됩니다. 처음 한 번은 치지직 개발자 사이트에서 내 봇용 열쇠(API 키)를 발급받아야 하는데, 무료이고 설치 안내가 화면에 그대로 나와서 3분이면 끝나요. 봇 전용 이름을 쓰고 싶다면 네이버 부계정이 하나 더 필요합니다.

방송 안 할 때도 켜둬야 하나요?

아니요. 방송할 때만 켜면 됩니다. 꺼도 출석 기록과 설정은 전부 남아 있어요.

결제하면 어떻게 이용하나요?

스마트스토어에서 결제한 뒤, 아인 설정 → [이용권]에 주문번호를 붙여넣으면 즉시 기간이 늘어납니다. 기다릴 것도, 받을 것도 없어요. 무료 체험이 남아 있으면 남은 날짜도 그대로 보존됩니다.

다른 봇을 쓰다가 넘어와도 되나요?

네. 시청자 출석 횟수를 이어받는 기능이 있어서, 단골 시청자들의 기록이 처음부터 다시 시작되지 않게 할 수 있습니다.
