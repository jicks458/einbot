# 아인 — 나만의 치지직 채팅봇

치지직(CHZZK) 방송용 설치형 채팅봇 **아인**의 공식 사이트 저장소입니다.

- 공식 사이트: https://einbot.kr/
- Microsoft Store 설치: https://apps.microsoft.com/detail/9nw8q03rgqlv
- 사용 가이드: https://einbot.kr/guide/
  - [치지직 채팅봇 설치 방법](https://einbot.kr/guide/install/)
  - [명령어 목록과 설정 방법](https://einbot.kr/guide/commands/)
  - [출석 체크 봇 설정 방법](https://einbot.kr/guide/attendance/)
  - [후원·구독 감사 인사 자동으로 하기](https://einbot.kr/guide/donation/)

## 아인이 하는 일

- 시청자 출석 체크 (누적 횟수 기억, 인사말만 쳐도 출석)
- 치즈 후원·구독·구독권 선물 감사 인사
- `!출첵` `!팔로우` `!업타임` `!시간` 기본 명령어와 채팅에서 바로 만드는 내 명령어
- 네이버 부계정을 연결하면 직접 지은 이름으로 응답
- 반복 공지

Windows 10·11 전용. 7일 무료 체험 후 1개월 2,900원부터.

문의: einbot.help@gmail.com

> 아인은 개인이 개발한 프로그램으로, 네이버(주) 및 치지직의 공식 서비스가 아닙니다. "치지직"은 네이버(주)의 상표입니다.
