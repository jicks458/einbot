## 아인이 하는 일

- 시청자 출석 체크 (누적 횟수 기록, 인사말만 입력해도 출석)
- 오늘 채팅한 시청자를 모아 보는 출석부
- 치즈 후원·구독·구독권 선물·새 팔로우 감사 인사
- `!출첵` `!팔로우` `!업타임` `!시간` 기본 명령어와 채팅에서 바로 만드는 내 명령어
- 반복 공지
- 방송 시작 디스코드 알림
- 네이버 부계정을 연결하면 직접 지은 이름으로 응답 (연결하지 않으면 "아인 봇")
- 투표·추첨·돌림판·후원 룰렛, 카운터·타이머·스톱워치를 OBS 방송 화면에 표시
- 채팅 오버레이·알림 오버레이, 유튜브 신청곡, TTS 읽어주기, TITS 던지기

Windows 10·11 전용. 30일 무료 체험 후 1개월 2,900원부터.

문의: 디스코드 https://einbot.kr/discord · 메일 einbot.help@gmail.com

> 아인은 개인이 개발한 프로그램으로, 네이버(주) 및 치지직의 공식 서비스가 아닙니다. "치지직"은 네이버(주)의 상표입니다.
