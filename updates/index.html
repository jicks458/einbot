1.7.2 2026년 9월 9일

스토어 버전 1.7.2.0 · 스토어 심사 중

  • 구독 인사 방식 변경. 시청자가 구독·갱신 뒤 채팅에 올린 구독 메시지에만 인사합니다. 조용히 갱신한 시청자나 방송 밖 갱신에는 인사하지 않습니다. 시청자가 알리고 싶을 때만 함께 축하하는 방식입니다.
  • "구독 조회" 권한이 필요 없어졌습니다. 개발자 센터 앱에 이 권한이 없어도 구독·구독권 선물 인사가 동작합니다. 권한이 없어 구독 인사가 안 나가던 문제가 이것으로 풀립니다. 필요한 권한은 유저 조회, 채팅 메시지 조회, 채팅 메시지 쓰기, 후원 조회 4개입니다.
  • 노란 알림 띠. 후원 조회 권한이 빠진 것처럼 로그에서 놓치기 쉬운 문제를 아인 창 위에 띠로 보여주고, 누르면 해결 방법 페이지가 열립니다.
  • 진단 정보 전송량을 줄였습니다. 후원 카드는 형태만 실행당 한 번, 같은 안내가 겹쳐 오면 한 번만 보냅니다.

1.7.1 2026년 9월 8일

스토어 버전 1.7.1.0

  • 문제 해결용 진단 정보 전송. 오류와 이벤트의 종류만 운영자 서버로 보내 원인을 찾을 수 있게 했습니다. 채팅 내용, 시청자 닉네임, 후원 메시지, API 키·로그인 정보는 보내지 않고, 30일 뒤 자동 삭제됩니다. 설정 → API·계정 → [진단 정보 보내기]에서 끌 수 있습니다. 자세한 내용은 개인정보처리방침에 있습니다.
  • 구독권 선물 안내가 방송마다 다른 형태로 오는 문제를 이 정보로 확인해 다음 버전에서 고칩니다.

1.7 2026년 9월 7일

스토어 버전 1.7.0.0

  • 설정이 바로 반영됩니다. 설정 화면에서 저장하면 봇을 껐다 켜지 않아도 명령어, 문구, 반복 공지가 즉시 적용됩니다. API 키와 봇 계정을 바꿨을 때만 다시 시작하면 됩니다.
  • 방장·매니저 채팅 명령어 수정. 채팅창에서 !명령어추가 같은 방장 전용 명령어가 반응하지 않던 문제를 고쳤습니다.
  • 티어별 구독 인사. 2티어 이상 구독에만 "2티어 구독"처럼 티어를 붙여 인사하고, 티어마다 다른 문구를 두는 칸이 생겼습니다. 치환자 {티어표시} {티어번호} 추가.
  • 구독권 선물 인사 정리. 선물한 분께만 인사하고, 선물받은 분의 구독 시작에는 따로 인사하지 않습니다. 익명 선물은 "익명의 후원자"로 인사합니다.
  • 후원·구독·선물 안내를 놓치지 않도록 채팅 수신 방식을 보강하고, 앱 로그에 안내 종류를 남깁니다.

1.6.4 2026년 9월 5일

스토어 버전 1.6.4.0

  • 작업표시줄 아이콘 뒤에 남던 사각 배경판을 없앴습니다.

1.6 2026년 9월 4일

스토어 버전 1.6.2.0

  • Microsoft Store 정식 등록. 내려받기와 압축 해제 없이 스토어에서 설치하고, 업데이트도 스토어가 자동으로 합니다.
  • 예전 압축 파일 방식으로 쓰던 분은 스토어에서 설치하면 설정, 시청자 출석 기록, 이용권이 그대로 넘어오고, 옛 버전은 물어본 뒤 정리합니다.
  • 첫 실행 때 바탕화면 바로가기를 만듭니다.
  • 이용권과 체험 기간을 채널 기준으로 서버에 기록해, PC를 바꾸거나 다시 설치해도 이어집니다.

1.5 2026년 8월 27일

첫 공개판 (압축 파일 배포)

  • 시청자가 인사만 해도 기록되는 출석 체크와 누적 횟수 인사, 처음 온 분·오랜만인 분 문구.
  • 치즈 후원, 구독, 구독권 선물 감사 인사.
  • 기본 명령어, 채팅에서 바로 만드는 내 명령어, 반복 공지.
  • 네이버 부계정을 연결해 내가 지은 이름으로 응답하는 봇 계정 기능.
  • 7일 무료 체험과 이용권.
