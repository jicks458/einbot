2.0 2026년 9월 24일

스토어 버전 2.0.0.0

  • 새 메인 창. 켜고 끄는 창을 처음부터 다시 그렸습니다. 위쪽 상태 카드에서 실행 중인지 꺼져 있는지와 어떤 이름으로 응답하는지가 한눈에 보이고, 오른쪽 [시작]/[중지] 하나로 켜고 끕니다. 아래에는 설정·기능 바로가기 타일, 맨 아래에 버전과 다크 모드 버튼이 있습니다. 창 안의 기록 칸은 없앴습니다(기록 파일은 그대로 data\logs 에 남습니다). 제목 표시줄도 테마 색을 따릅니다.
  • 구독자 뽑기. 추첨의 뽑기 카드 아래에 [구독자 뽑기]가 생겼습니다. 뽑힌 사람의 구독 여부를 그때 확인해 구독자가 아니면 건너뛰고 다시 뽑습니다. 참여는 누구나, 확인은 뽑는 순간에만 하므로 사람이 많아도 느려지지 않습니다. 방송 중일 때만 확인할 수 있습니다.
  • 구독자 표시. 추첨 참여자 칸의 "구독자 표시"를 켜면 구독자 수와 명단 색(보라)으로 누가 구독자인지 기능 창에서 볼 수 있습니다. 방송 화면에는 표시되지 않습니다. 처음에는 꺼져 있습니다.
  • 투표 재개·번호. 투표를 종료하면 [투표 시작]이 [투표 재개]로 바뀌어 같은 투표를 이어 받을 수 있습니다. [지우기]는 [초기화]로 이름을 바꿨고, 보기의 번호를 시청자가 치는 숫자 그대로 크게 보이게 했습니다.
  • 투표 가리기. 켜면 방송 화면뿐 아니라 기능 창에서도 종료할 때까지 표 수가 "?"로 보입니다. 스위치 이름도 "결과 가리기 (종료 때까지 시청자에게 숨김)"에서 "투표 가리기"로 줄였습니다.
  • 글꼴·문구·아이콘 정리. 메인 창, 기능 창, 설정 창, 첫 설정 안내, 오버레이가 모두 Pretendard 글꼴을 내장해 어느 PC에서나 같은 모양으로 보입니다. 안내 문구를 짧고 격식 있는 문장으로 다시 썼고, 목차와 버튼의 이모지는 선 아이콘으로 바꿨습니다. 목차 아이콘은 묶음별 색 타일 위에 놓여 한눈에 구분됩니다.
  • 다크 모드 손질. 눈부시던 초록 버튼과 칩을 짙은 초록으로 낮추고, 스크롤바와 창 제목 표시줄도 어둡게 맞췄습니다.

스토어 버전 1.9.0.0

  • 알림 오버레이. 후원·구독·구독권 선물·룰렛 결과·투표 결과·추첨 당첨·타이머 종료를 카드로 띄웁니다. 종류별로 끄고 켜고 표시 시간을 정합니다. 권장 크기 560×200.
  • TTS 읽어주기. 구독·구독권 선물·채팅을 Windows 내장 한국어 음성으로 읽습니다. 처음에는 꺼져 있고, 켜면 다음 채팅부터 읽습니다. 속도, 최대 글자, 밀림 허용, 금지어, 안 읽을 사람을 정할 수 있습니다. 봇의 답변과 !명령어는 읽지 않고, 후원 메시지는 치지직 자체 후원 알림이 읽어 주므로 여기서는 읽지 않습니다. 추첨의 당첨자 채팅 TTS는 그대로입니다.
  • TITS 던지기. 후원·구독·구독권 선물·채팅 키워드에 맞춰 VTube Studio 아바타에 물건을 던집니다. TITS는 별도 유료 프로그램입니다(Steam ₩21,500). 규칙마다 아이템(여러 개면 무작위)·개수·비례·트리거를 정하고, 구독·구독권 선물 규칙에는 2티어 가지가 붙어 따로 정할 수 있습니다. 처음에는 꺼져 있습니다. 가이드
  • 다크 모드. 아인 창 오른쪽 아래 버튼으로 바꾸면 설정·기능·초기 설정 창까지 바로 따라갑니다.
  • 후원 룰렛이 처음에는 꺼져 있습니다. 1.8.0은 켜진 채로 설치되어 룰렛을 만들지 않은 방송에서도 1,000원 후원에 결과가 채팅에 나갔습니다. 1.9.0으로 올라가면 룰렛 규칙과 문구를 손대지 않은 설정은 자동으로 꺼지고, 쓰려면 기능 창에서 [후원 룰렛 사용]을 켜고 저장하면 됩니다. 끄면 새 후원부터 멈추고, 이미 들어온 후원의 회전은 마저 돕니다.
  • 구독·구독권 선물의 티어. 1티어는 티어를 말하지 않고 2티어부터 "2티어"라고 말합니다. 채팅 인사({티어표시}), 알림 카드, TTS 모두 같은 규칙이고, 구독권 선물 기본 문구에도 {티어표시}가 들어갔습니다.
  • 룰렛·돌림판 오버레이. 원판이 소스 한가운데에 오고, 긴 결과(20연차 등)도 원판 폭 안에서 줄바꿈합니다. 결과 상자가 조금 아래로, 글자는 조금 크게. 권장 크기 490×640.
  • [기능]·[설정] 버튼을 다시 누르면 창이 다시 열립니다. 창을 잃어버렸을 때 쓰세요.
  • 당첨자 채팅 TTS를 포함해 음성 출력이 PowerShell 없이 동작합니다. 보안 프로그램이 오탐할 여지를 없앴습니다.
  • 진단 정보의 기능별 사용 횟수에 후원 룰렛 켬·끔 저장과 TITS 던지기 횟수가 추가됐습니다. 채팅 내용·이름은 보내지 않습니다.

1.8.0 2026년 9월 19일

스토어 버전 1.8.0.0

  • [기능] 버튼과 기능 창. 아인 창 [설정] 아래에 [기능]이 생겼습니다. 왼쪽 목록에서 투표·추첨·돌림판·후원 룰렛(참여 기능)과 카운터·타이머·스톱워치(시간 기능)를 고르고 버튼으로 진행합니다. 시청자 쪽 명령어는 없습니다. 투표는 채팅에 번호만, 추첨은 채팅 한 줄(또는 정한 키워드). 참여 기능 가이드 · 시간 기능 가이드
  • OBS 오버레이. 각 기능마다 브라우저 소스 주소가 있어 방송 화면에 투표 막대, 참여 인원, 돌아가는 룰렛, 카운터·타이머·스톱워치를 띄웁니다. 배경 투명, 글자 크기·색은 한 번에 조절.
  • 후원 룰렛. 정한 금액이 후원되면 화면에서 자동으로 돌고 결과가 채팅에 올라갑니다. 감지 키워드, 연차(배수만큼 회전), 하루 횟수 제한. 오버레이를 안 열어 두어도 채팅 결과는 나갑니다.
  • 봇 계정 로그인 창. 부계정 연결이 [봇 계정으로 로그인] 버튼 하나로 바뀌었습니다. 열리는 창에서 부계정으로 로그인하면 아인이 저장하고 창을 닫습니다. 개발자 도구에서 쿠키를 복사하는 단계가 없어졌습니다(직접 입력은 남겨 둠).
  • 설정 화면이 목록형으로. 길게 이어지던 명령어 설정을 왼쪽 목록(치지직 연결·봇 계정·이용권·기본 설정·출석·기본 명령어·내 명령어·후원·구독·반복 공지·진단·문제 해결)으로 나눴습니다.
  • !봇 명령어. 시청자나 다른 방송인이 !봇(!채팅봇, !치지직봇)을 치면 아인을 소개합니다. 문구는 바꾸거나 끌 수 있습니다.
  • 작업 표시줄에서 설정 창과 기능 창이 각자 아이콘으로 구분됩니다. 바탕화면 바로가기 아이콘이 업데이트 뒤 백지로 나오던 문제를 고쳤습니다.
  • 추첨 화면. 방송 화면에 참여자 명단이 보이고(끌 수 있음), 뽑을 때 초록 테두리가 닉네임 사이를 점점 빠르게 돌다 당첨자에 멈춰 깜빡입니다. 더 뽑으면 이미 뽑힌 사람은 빼고 돕니다. 당첨자 한 명이면 그 사람과 그 사람의 채팅이 화면에 뜨고, Windows 내장 음성이 그 채팅을 읽어 줍니다(둘 다 끌 수 있음). 명단에서 아무 닉네임이나 눌러 띄울 수도 있습니다. 모집은 시작 → 마감 → 재개 한 버튼입니다.
  • 후원 룰렛의 다회차. 정한 금액의 몇 배가 오면 그만큼 걸쇠가 원판 가장자리에 날아와 박힌 뒤 한 번만 돌고, 결과를 "꽝×4, 노래 한 곡×1"처럼 모아 화면과 채팅에 알립니다. 룰렛이 도는 후원에는 감사 인사를 따로 보내지 않습니다. [연차 테스트]로 미리 볼 수 있습니다.
  • 투표 화면. 1위 보기 왼쪽에 초록 선이 붙고(동표면 모두), 끝나면 깜빡입니다. 결과 가리기 중에는 선도 숨깁니다.
  • 타이머. 시작·일시정지·계속이 한 버튼이 됐고, [직접]을 고를 때만 분을 넣습니다. 방송 화면의 시계가 매초 되감기던 것을 고쳤습니다.
  • 오버레이 URL은 고정. 각 화면의 URL 옆에 권장 크기가 붙었고, 앞으로 업데이트해도 URL과 포트는 바뀌지 않습니다. 시간 기능 화면은 글자를 키워 또렷해졌습니다.
  • 로그인 창(스트리머·봇 계정)이 InPrivate로, 같은 크기로, 아인 창 옆에 앞으로 뜹니다. 로그인 때 "Node.js 허용" 방화벽 경고가 더 이상 뜨지 않습니다. 앱을 종료하면 설정·기능 창도 같이 닫힙니다.
  • 앱을 처음 실행할 때 익명 설치 식별자와 버전만 한 번 보냅니다(설치 뒤 설정을 마치지 못한 분이 얼마나 되는지 알기 위해). 채널·이름은 포함되지 않고, [진단 정보 보내기]를 끄면 보내지 않습니다. 개인정보처리방침

1.7.3 2026년 9월 10일

스토어 버전 1.7.3.0

  • 구독권 선물 감사 인사가 실제로 나갑니다. 치지직이 선물 안내를 글이 아닌 별도 형식으로 보낸다는 것을 실제 방송에서 확인해, 그 형식을 직접 읽도록 고쳤습니다. 익명 선물은 "익명의 후원자"로 인사하고, 한 사람이 여러 장을 선물하면 개수를 모아 한 번만 인사합니다. 선물받은 분의 구독 메시지에는 따로 인사하지 않습니다.

1.7.2 2026년 9월 9일

스토어 버전 1.7.2.0

  • 구독 인사 방식 변경. 시청자가 구독·갱신 뒤 채팅에 올린 구독 메시지에만 인사합니다. 조용히 갱신한 시청자나 방송 밖 갱신에는 인사하지 않습니다. 시청자가 알리고 싶을 때만 함께 축하하는 방식입니다.
  • "구독 조회" 권한이 필요 없어졌습니다. 개발자 센터 앱에 이 권한이 없어도 구독·구독권 선물 인사가 동작합니다. 권한이 없어 구독 인사가 안 나가던 문제가 이것으로 풀립니다. 필요한 권한은 유저 조회, 채팅 메시지 조회, 채팅 메시지 쓰기, 후원 조회 4개입니다.
  • 노란 알림 띠. 후원 조회 권한이 빠진 것처럼 로그에서 놓치기 쉬운 문제를 아인 창 위에 띠로 보여주고, 누르면 해결 방법 페이지가 열립니다.
  • 진단 정보 전송량을 줄였습니다. 후원 카드는 형태만 실행당 한 번, 같은 안내가 겹쳐 오면 한 번만 보냅니다.

1.7.1 2026년 9월 8일

스토어 버전 1.7.1.0

  • 문제 해결용 진단 정보 전송. 오류와 이벤트의 종류만 운영자 서버로 보내 원인을 찾을 수 있게 했습니다. 채팅 내용, 시청자 닉네임, 후원 메시지, API 키·로그인 정보는 보내지 않고, 30일 뒤 자동 삭제됩니다. 설정 → API·계정 → [진단 정보 보내기]에서 끌 수 있습니다. 자세한 내용은 개인정보처리방침에 있습니다.
  • 구독권 선물 안내가 방송마다 다른 형태로 오는 문제를 이 정보로 확인해 다음 버전에서 고칩니다.

1.7 2026년 9월 7일

스토어 버전 1.7.0.0

  • 설정이 바로 반영됩니다. 설정 화면에서 저장하면 봇을 껐다 켜지 않아도 명령어, 문구, 반복 공지가 즉시 적용됩니다. API 키와 봇 계정을 바꿨을 때만 다시 시작하면 됩니다.
  • 방장·매니저 채팅 명령어 수정. 채팅창에서 !명령어추가 같은 방장 전용 명령어가 반응하지 않던 문제를 고쳤습니다.

  • 후원·구독·선물 안내를 놓치지 않도록 채팅 수신 방식을 보강하고, 앱 로그에 안내 종류를 남깁니다.
