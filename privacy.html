아인

개인정보처리방침

시행일: 2026년 8월 27일

아인(이하 "프로그램")은 이용자의 개인정보를 소중히 다룹니다. 이 방침은 프로그램과 운영자가 어떤 정보를 어떻게 처리하는지 설명합니다.

핵심 요약
  • 프로그램은 이용자 본인의 컴퓨터에서 실행됩니다.
  • 치지직 로그인 정보, 시청자 출석 기록, 설정 등은 이용자 컴퓨터에만 저장되며 외부로 전송되지 않습니다.
  • 운영자 서버로 전송되는 것은 이용권 확인에 필요한 최소한의 정보(연장 코드 또는 주문번호)뿐입니다.
  • 별도의 광고·추적·행태정보 수집을 하지 않습니다.

1. 이용자 컴퓨터에 저장되는 정보

아래 정보는 프로그램이 동작하기 위해 이용자 컴퓨터 내부에만 저장되며, 운영자를 포함한 외부로 전송되지 않습니다.

  • 치지직 로그인 정보(액세스·리프레시 토큰) 및 개발자 API 키
  • 봇 계정(부계정)으로 사용하는 경우의 로그인 쿠키
  • 시청자 출석 기록(닉네임·누적 횟수), 명령어 설정 및 문구
  • 프로그램 동작 로그

이 정보들은 이용자가 프로그램을 삭제하면 함께 제거됩니다(이용권 관련 최소 기록은 예외 — 아래 4항 참고).

2. 운영자 서버로 전송되는 정보

다음의 경우에 한해, 이용권 확인에 필요한 최소한의 정보가 운영자 서버로 전송됩니다.

  • 연장 코드 등록 시: 입력한 연장 코드. 코드의 정당성과 최초 사용 여부를 확인하기 위함입니다.
  • 주문번호 등록 시: 입력한 스마트스토어 주문번호. 결제 완료 여부를 확인하기 위함입니다.
  • 버전 확인 시: 새 버전 여부를 확인하기 위한 요청. 개인을 식별하는 정보는 포함되지 않습니다.

이용권은 이용자의 치지직 채널 식별자를 기준으로 관리되며, 이는 중복 사용 방지 및 이용 기간 산정 목적으로만 사용됩니다.

3. 제3자 서비스

  • 치지직(네이버): 프로그램은 이용자를 대신해 치지직 공식 API에 연결하여 채팅·후원·구독 정보를 주고받습니다. 이는 이용자가 직접 로그인·동의한 범위 내에서 이루어집니다.
  • Cloudflare: 이용권 확인 서버와 웹사이트 운영에 사용됩니다.
  • 네이버 커머스(스마트스토어): 주문번호로 결제 여부를 확인할 때 이용됩니다.

4. 보관 기간

운영자 서버에는 이용권 관리를 위해 사용된 코드·주문번호의 사용 여부와 이용 기간 정보가 보관됩니다. 이는 중복 사용 방지와 정당한 이용 기간 보장을 위한 것으로, 결제·환불 분쟁 대응에 필요한 기간 동안 보관됩니다.

5. 이용자의 권리

이용자는 프로그램을 삭제함으로써 자신의 컴퓨터에 저장된 정보를 언제든 제거할 수 있습니다. 운영자 서버에 보관된 이용권 정보의 확인·삭제를 원하시면 아래 연락처로 요청해 주세요.

6. 아동의 개인정보

프로그램은 만 14세 미만 아동을 대상으로 하지 않습니다.
