개인정보처리방침

시행일: 2026년 8월 27일 · 2026년 9월 21일 개정(1항에 기능 창 설정, 3항에 글꼴 CDN·TITS 연동 항목 추가) · 2026년 9월 23일 개정(1항에 디스코드 웹훅 주소·연결 계정 이름, 3항에 디스코드 연결 항목 추가) · 2026년 9월 25일 개정(1항에 신청곡 대기열·재생 기록, 3항에 유튜브 항목 추가) · 2026년 9월 26일 개정(2항 최초 실행 신호에 초기 설정 진행 단계 추가, 2.1.1부터)

아인(이하 "프로그램")은 이용자의 개인정보를 소중히 다룹니다. 이 방침은 프로그램과 운영자가 어떤 정보를 어떻게 처리하는지 설명합니다.

핵심 요약
  • 프로그램은 이용자 본인의 컴퓨터에서 실행됩니다.
  • 치지직 로그인 정보, 시청자 출석 기록, 설정 등은 이용자 컴퓨터에만 저장되며 외부로 전송되지 않습니다.
  • 운영자 서버로 전송되는 것은 이용권 확인에 필요한 최소한의 정보(연장 코드 또는 주문번호)뿐입니다.
  • 별도의 광고·행태정보 수집을 하지 않습니다. 이 웹사이트의 방문 통계만 네이버 애널리틱스로 익명 집계됩니다.

1. 이용자 컴퓨터에 저장되는 정보

아래 정보는 프로그램이 동작하기 위해 이용자 컴퓨터 내부에만 저장되며, 운영자를 포함한 외부로 전송되지 않습니다.

  • 치지직 로그인 정보(액세스·리프레시 토큰) 및 개발자 API 키
  • 봇 계정(부계정)으로 사용하는 경우의 로그인 쿠키
  • 시청자 출석 기록(닉네임·누적 횟수), 명령어 설정 및 문구
  • 프로그램 동작 로그
  • 기능 창 설정(투표·추첨·룰렛·채팅 오버레이·신청곡·TTS·TITS 규칙)과 룰렛 결과 기록
  • 디스코드 알림을 켠 경우 디스코드 웹훅 주소와 마지막으로 알린 방송의 시작 시각 (1.9.3)
  • 설정 창에 "지금 연결된 계정"을 보여 주기 위한 방송 계정의 채널 이름·채널 ID와 봇 계정의 닉네임 (1.9.3)
  • 신청곡을 켠 경우 신청곡 대기열과 최근 재생 기록(유튜브 영상 ID·제목·채널 이름, 신청한 시청자의 닉네임·채널 ID, 신청 시각. 재생 기록은 최근 100곡까지) (2.1)

이 정보들은 이용자가 프로그램을 삭제하면 함께 제거됩니다(이용권 관련 최소 기록은 예외 — 아래 4항 참고).

2. 운영자 서버로 전송되는 정보

다음의 경우에 한해, 이용권 확인에 필요한 최소한의 정보가 운영자 서버로 전송됩니다.

  • 연장 코드 등록 시: 입력한 연장 코드. 코드의 정당성과 최초 사용 여부를 확인하기 위함입니다.
  • 주문번호 등록 시: 입력한 스마트스토어 주문번호. 결제 완료 여부를 확인하기 위함입니다.
  • 버전 확인 시: 새 버전 여부를 확인하기 위한 요청. 개인을 식별하는 정보는 포함되지 않습니다.
  • 이용권 동기화 시: 치지직 채널 식별자. 프로그램을 재설치해도 무료 체험 기간과 구매한 이용권이 그대로 이어지도록 하기 위한 것으로, 이 목적 외에는 사용되지 않습니다.
  • 진단 정보 전송 시 (1.7.1부터): 프로그램 버전, 봇의 시작·연결 상태, 오류 메시지, 치지직 안내 이벤트의 종류 번호와 닉네임을 가린 안내문, 명령어·기능 종류별 사용 횟수(투표·룰렛·TITS 등), 후원 금액 구간, 치지직 채널 식별자. 오류의 원인을 찾기 위한 것으로, 채팅 내용·시청자 닉네임·후원 메시지·API 키·로그인 쿠키·출석 기록은 포함되지 않습니다. 설정 화면의 [진단 정보 보내기]를 끄면 전송되지 않습니다.
  • 최초 실행 신호 (1.8.0부터): 앱을 처음 실행할 때 이 컴퓨터에서 만든 무작위 설치 식별자와 프로그램 버전, 스토어 설치 여부를 한 번 전송합니다. 설치 뒤 초기 설정을 마치지 못한 이용자가 얼마나 되는지 파악해 설치 과정을 고치기 위한 것으로, 치지직 채널·닉네임·IP 주소는 포함되지 않습니다. 2.1.1부터는 같은 설치 식별자로 초기 설정 진행 단계(어느 화면까지 진행했는지, 막힌 단계의 종류 — 예: 키 형식 오류, 로그인 실패)도 함께 전송합니다. 입력한 API 키·로그인 정보·이름은 포함되지 않습니다. 설정 화면의 [진단 정보 보내기]를 끄면 전송되지 않습니다.

이용권은 이용자의 치지직 채널 식별자를 기준으로 관리되며, 이는 중복 사용 방지 및 이용 기간 산정 목적으로만 사용됩니다.

3. 제3자 서비스

  • 치지직(네이버): 프로그램은 이용자를 대신해 치지직 공식 API에 연결하여 채팅·후원·구독 정보를 주고받습니다. 이는 이용자가 직접 로그인·동의한 범위 내에서 이루어집니다.
  • Cloudflare: 이용권 확인 서버와 웹사이트 운영에 사용됩니다.
  • 네이버 커머스(스마트스토어): 주문번호로 결제 여부를 확인할 때 이용됩니다.
  • 네이버 애널리틱스: 이 웹사이트(einbot.kr)의 방문 통계(방문 수·유입 경로)를 익명으로 집계하기 위해 사용됩니다. 프로그램(아인) 자체에는 적용되지 않습니다.
  • 디스코드(discord.com): 디스코드 알림을 켠 경우에만, 방송이 시작될 때 이용자가 넣은 웹훅 주소로 방송 제목·카테고리·방송 링크·썸네일 주소·채널 이름·봇 이름을 보냅니다. 시청자 정보는 보내지 않습니다. (1.9.3)
  • 글꼴 CDN(jsdelivr, Google Fonts): 설정 화면과 방송 화면 오버레이가 글꼴 파일을 내려받을 때 연결됩니다. 개인정보는 전송되지 않습니다.
  • TITS(Twitch Integrated Throwing System): 이용자가 TITS 연동을 켠 경우에만, 같은 컴퓨터 안(127.0.0.1)에서 실행 중인 TITS에 아이템 던지기·트리거 실행 요청을 보냅니다. 인터넷으로 나가지 않으며 채팅 내용·닉네임은 보내지 않습니다. TITS와 VTube Studio는 각 개발사의 정책을 따릅니다.
  • 유튜브(YouTube, Google): 이용자가 신청곡을 켠 경우에만 연결됩니다. 신청된 영상의 제목·채널 이름을 확인하려고 유튜브의 공개 oEmbed 주소(youtube.com)에 영상 주소를 보내고, 방송 화면과 플레이어 창에서는 유튜브 공식 플레이어(IFrame Player API)로 영상을 재생하며 썸네일을 i.ytimg.com에서 불러옵니다. 이때 이용자 컴퓨터의 IP 주소 등 브라우저가 보내는 정보가 유튜브에 전달될 수 있고, 이는 유튜브·Google의 개인정보처리방침을 따릅니다. 시청자 닉네임·채팅 내용은 보내지 않습니다. (2.1)

4. 보관 기간

운영자 서버에는 이용권 관리를 위해 사용된 코드·주문번호의 사용 여부와 이용 기간 정보가 보관됩니다. 이는 중복 사용 방지와 정당한 이용 기간 보장을 위한 것으로, 결제·환불 분쟁 대응에 필요한 기간 동안 보관됩니다. 진단 정보는 전송일로부터 30일 뒤 자동으로 삭제됩니다.

5. 이용자의 권리

이용자는 프로그램을 삭제함으로써 자신의 컴퓨터에 저장된 정보를 언제든 제거할 수 있습니다. 운영자 서버에 보관된 이용권 정보의 확인·삭제를 원하시면 아래 연락처로 요청해 주세요.
