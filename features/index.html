봇 이름·로그인

설치 가이드 →
  • 우리 방송만의 봇 이름네이버 부계정을 연결하면 그 닉네임이 봇 이름. 신청도 승인도 없음
  • 키 없이 로그인API 키 발급 없이 방송 계정으로 로그인만 하면 시작
  • 봇 계정 로그인 창쿠키 복사 없음. [로그인 상태 유지]는 아인이 켜 둠
  • 로그인 풀림 알림치지직 로그인이 풀리면 노란 띠와 알림, 다시 로그인하면 봇이 이어서 켜짐
  • 봇 계정 연결 끊김 알림부계정 연결이 끊기면 아인 창이 알려 줌
  • 봇 계정 기본 그림부계정을 처음 연결할 때 아인 그림을 넣어 줌 (끌 수 있음)

출석

출석 체크 가이드 →
  • 인사말만으로 자동 출석"안녕하세요"처럼 정해 둔 인사말을 치면 출석
  • !출첵·!출석 명령어 출석명령어로도 출석. 둘 다 기본 제공
  • 누적 출석 횟수 인사"12번째 출석"처럼 횟수를 세어 반김
  • 상황별 출석 문구 4가지처음 온 사람, 오랜만인 사람, 단골 등 문구를 따로
  • 하루 기준 시각새벽 방송이면 하루의 시작을 내 시각으로
  • 다른 봇 출석 기록 이어받기쓰던 봇의 횟수를 넣어 두면 이어서 셈

후원·구독·팔로우 인사

감사 인사 가이드 →
  • 치즈 후원 감사 인사금액·메시지를 문구에 넣음. 익명 후원도 처리
  • 구독 감사 인사티어별로 문구를 다르게
  • 구독권 선물 감사 인사랜덤 선물은 개수 그대로 한 번에 인사
  • 팔로우 감사 인사새로 팔로우한 분께 1~2초 안에 채팅으로. 봇 계정을 채널 관리자로 지정

명령어·공지

명령어 가이드 →
  • 기본 명령어!출첵 !팔로우 !업타임 !시간 !봇
  • 채팅에서 명령어 추가·삭제설정 창을 열지 않고 채팅으로 바로
  • 방장·매니저 전용 명령어시청자는 못 쓰는 명령어
  • 치환자{이름} {호칭} {금액} 같은 값을 문구에 넣음
  • 반복 공지정한 간격으로 공지를 채팅에
  • 방송 시작 디스코드 알림웹훅 주소만 넣으면 방송을 켤 때 디스코드 채널에 알림
  • 문구와 명령어 기호 바꾸기봇이 하는 말과 명령어 앞 기호를 내 방송에 맞게

시청자 참여

참여 기능 가이드 →

  • 돌림판항목을 넣고 돌려서 고름

방송 화면 (OBS 오버레이)

오버레이 가이드 →

  • 투표·추첨·룰렛 오버레이기능 창에서 진행하면 OBS 화면에 바로
  • 카운터·타이머·스톱워치 오버레이브라우저 소스 하나로
  • 오버레이 꾸미기글꼴·색·크기를 내 화면에 맞게
  • 곡 제목 표시지금 나오는 신청곡 제목을 화면에
  • 다크 모드오버레이를 어두운 화면에 맞게
