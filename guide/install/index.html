치지직 채팅봇 설치 방법 — 아인 5분 설치 가이드

치지직 채팅봇 아인을 방송에 붙이는 순서입니다. 파일을 내려받거나 압축을 풀 일은 없고, 손이 가는 건 치지직 개발자 센터에서 내 봇용 열쇠를 한 번 발급받는 것뿐입니다.

준비물

  • Windows 10 또는 11 PC. 봇은 이 컴퓨터에서 돌아가므로 방송 중에는 켜 두어야 합니다.
  • 치지직에 로그인한 적 있는 네이버 계정. 방송하는 그 계정이면 됩니다. 계정이 없다면 네이버 회원가입 뒤 치지직에 한 번 로그인해 두세요.
  • (선택) 봇 이름용 네이버 부계정. "○○봇"처럼 직접 지은 이름으로 응답하게 하고 싶을 때만 필요합니다. 나중에 추가해도 됩니다.

회원가입이나 카드 등록은 없습니다. 설치하면 7일 동안 모든 기능을 무료로 쓸 수 있습니다.

1Microsoft Store에서 설치

아인은 Microsoft Store에 정식 등록되어 있습니다. 아래 버튼을 누르거나, Windows의 Microsoft Store 앱에서 아인을 검색해 [설치]를 누르세요.

Microsoft Store에서 설치하기 설치 파일 내려받기, 압축 해제, "확인되지 않은 앱" 경고가 전부 없습니다. 새 버전은 스토어가 알아서 업데이트합니다.

회사 PC처럼 Microsoft Store가 막힌 환경이라면 einbot.help@gmail.com 으로 문의해 주세요.

2아인 실행

설치가 끝나면 시작 메뉴에서 아인을 엽니다. 첫 실행 때 바탕화면에 바로가기가 자동으로 생기니 다음부터는 거기서 열면 됩니다.

처음 켜면 초기 설정 안내 화면이 순서대로 나옵니다. 아래 3·4·5단계가 그 화면의 순서와 같습니다.

3치지직 개발자 센터에서 API 키 발급

봇이 채팅을 읽고 쓰려면 치지직이 발급하는 열쇠가 필요합니다. 무료이고, 한 번만 하면 됩니다. 약 3분.

  1. developers.chzzk.naver.com 에 접속해 네이버로 로그인합니다. 방송하는 계정으로 로그인하세요.
  2. [애플리케이션 등록]을 누릅니다.
  3. 애플리케이션 이름은 자유롭게 짓되, 치지직 네이버 chzzk naver 는 넣을 수 없습니다. 넣으면 앱이 정지될 수 있습니다. 예: 내 방송 봇
  4. 로그인 리디렉션 URL 칸에 아래를 정확히 붙여넣습니다.
    http://localhost:3000/callback
  5. API Scopes에서 다음 5개를 모두 체크합니다.
    • 유저 조회
    • 채팅 메시지 조회
    • 채팅 메시지 쓰기
    • 후원 조회 — 치즈 후원 감사 인사에 필요
    • 구독 조회 — 구독·구독권 선물 감사 인사에 필요
  6. 등록을 마치면 Client ID와 Client Secret이 나옵니다. 두 값을 아인 화면의 칸에 붙여넣습니다.

권한 5개는 처음 등록할 때 한 번에 체크하세요. 등록 뒤에 권한을 바꾸면 치지직의 검수를 거쳐야 반영됩니다. 빠진 권한이 있으면 아인이 무엇이 빠졌는지 화면에 알려주니 그때 추가하면 됩니다.

4방송 계정으로 로그인

아인 화면의 [로그인 창 열기]를 누르면 깨끗한 로그인 창이 뜹니다. 방송하는 본인 계정으로 로그인하고 [동의]를 누르면 끝입니다.

로그인이 끝나면 화면에 연동된 채널 이름이 표시됩니다. 다른 계정으로 로그인했으면 아인이 알려주니, 로그아웃하고 방송 계정으로 다시 하면 됩니다.

5봇 이름 정하기 (선택)

이 단계를 건너뛰면 봇이 방송 계정 이름으로 응답합니다. "○○봇" 같은 전용 이름을 쓰려면 네이버 부계정을 하나 만들어 연결합니다. 화면에 그림 안내가 함께 나옵니다.

  • 부계정의 치지직 닉네임이 곧 봇 이름입니다. 치지직에서 닉네임을 먼저 정해 두세요. 프로필 아이콘 → 네이버 게임 프로필 → 프로필 편집에서 바꿉니다. 한 번 바꾸면 30일 동안 다시 바꿀 수 없으니 한 번에 정하세요.
  • 연결은 부계정의 로그인 정보를 아인에 한 번 넣는 방식입니다. [설정] → 봇 계정의 두 칸에 화면 안내대로 넣습니다. 봇이 돌아가는 동안 자동으로 연장되어 매번 다시 넣지 않아도 됩니다.

부계정은 봇 전용으로 두세요. 폰 등 다른 기기에서 같은 계정으로 로그인하면 봇 연결이 끊겨 다시 넣어야 할 수 있습니다.

연결 직후 네이버에서 "새로운 기기 로그인" 알림이 올 수 있는데, 그게 봇입니다. [로그아웃]이나 [내가 아님]을 누르지 마세요.

6봇 시작

앱 창의 봇 시작을 누르면 켜집니다. 방송 전에 켜 두면 되고, 방송이 끝나면 꺼도 출석 기록과 설정은 전부 남습니다.

치지직 채팅 서버는 방송 중에만 열립니다. 방송 전에 "봇 계정 연결 실패"라고 떠도 정상이고, 방송을 시작하면 자동으로 붙습니다.

이제 채팅창에서 !출첵 !시간 !업타임 같은 기본 명령어가 바로 됩니다. 문구와 명령어를 바꾸는 방법은 명령어 목록과 설정 방법을 참고하세요.

예전 방식(압축 파일)으로 설치했던 분

따로 할 일이 없습니다. 위 1단계대로 스토어에서 설치하면 설정, 시청자 출석 기록, 이용권이 그대로 넘어오고, 옛 버전은 지울지 물어본 뒤 정리해 줍니다.

옛 버전을 먼저 지우지 마세요. 지우면 그 안의 설정과 기록이 함께 사라져서 처음부터 다시 설정해야 합니다. 스토어 설치를 먼저 하고, 아인이 물어볼 때 [예]로 정리하는 순서가 맞습니다.

막힐 때

"권한이 빠졌습니다"라고 나와요

개발자 센터의 API Scopes에서 빠진 항목을 체크하세요. 아인이 정확히 어떤 권한이 빠졌는지 이름을 보여줍니다. 등록 뒤 변경은 치지직 검수 후 반영됩니다.

구독 인사만 안 나가요

"구독 조회" 권한이 빠진 경우입니다. 개발자 센터에서 추가하고 봇을 껐다 켜세요. 후원·구독 인사 설정은 따로 정리한 가이드가 있습니다.

"봇 계정 연결 끊김" 알림이 떠요

봇 이름용 부계정의 로그인이 풀린 것입니다. 부계정 비밀번호를 바꿨거나, 다른 기기에서 같은 계정을 썼거나, 봇을 몇 주 이상 안 켰을 때 생깁니다. 설정 화면의 안내대로 로그인 정보를 다시 넣으면 됩니다.

Microsoft Store를 쓸 수 없어요
