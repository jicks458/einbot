카운터·타이머·스톱워치 방송 화면에 띄우기

데스 수를 세거나, 라면 10분을 재거나, 도전 시간을 잴 때 씁니다. 아인 창의 [기능] 버튼 → 시간 기능에서 누르면 방송 화면이 바로 바뀝니다.

카운터

이름을 정해 만들면(예: 데스) 큰 숫자와 [−] [+] [0] 버튼이 생깁니다. 누를 때마다 방송 화면의 숫자가 바로 바뀝니다. 카운터는 여러 개 만들 수 있고 값은 봇을 껐다 켜도 남습니다.

오버레이 주소는 카운터마다 다릅니다. http://localhost:8391/overlay/counter/데스 처럼 이름이 붙습니다. 이름표 없이 숫자만 띄우려면 주소 뒤에 ?label=0.

타이머

5분·10분·30분·1시간 중 고르거나 분을 직접 넣고 [시작]. 이름(예: 라면)을 적어 두면 화면에 같이 나옵니다. [일시정지]와 [초기화]가 있고, 끝나면 채팅에 알릴 수 있습니다.

10분 뒤

초코우유 봇 ⏰ 라면 시간이에요!

문구는 기능 창에서 바꿉니다. {이름} 자리에 타이머 이름이 들어갑니다. 멈춰 있을 때 화면에서 감추려면 주소 뒤에 ?autohide=1.

스톱워치

[시작]으로 재기 시작해 [정지]로 멈추고 [계속]으로 이어 잽니다. [랩]을 누르면 그 순간의 기록이 아래에 쌓입니다(최근 20개). 0.1초 단위로 보입니다.

OBS에 띄우기

오버레이주소
카운터http://localhost:8391/overlay/counter/이름
타이머http://localhost:8391/overlay/timer
스톱워치http://localhost:8391/overlay/stopwatch

OBS에서 소스 추가 → 브라우저 → URL에 붙여넣기. 배경은 투명이라 원하는 자리에 놓으면 됩니다. 세 개를 따로 소스로 넣어 각각 다른 위치에 둘 수 있습니다.

화면 꾸미기

기능 창 왼쪽 맨 아래 오버레이 꾸미기에서 글자 크기(작게~아주 크게), 글자색, 배경(어둡게·밝게·없음), 그림자를 정하면 모든 오버레이에 같이 적용됩니다. 특정 소스만 다르게 하려면 주소 뒤에 ?크기=크게, ?배경=없음, ?글자색=%23111827 처럼 붙입니다.

자주 묻는 것

키보드 단축키로 카운터를 올릴 수 있나요?

지금은 기능 창의 버튼으로만 됩니다. 방송 중에 다른 프로그램을 쓰면서 누르는 전역 단축키는 다음 버전에서 넣을 예정입니다.

봇을 끄면 타이머가 사라지나요?

카운터 값은 남고, 진행 중이던 타이머와 스톱워치는 멈춥니다. 오버레이는 봇이 켜져 있을 때만 보입니다.
