치지직 채팅봇 아인 사용 가이드

설치부터 명령어, 출석 체크, 후원·구독 인사, 안 될 때 확인할 것까지. 앱의 실제 동작을 기준으로 씁니다.

  • 치지직 채팅봇 설치 방법

    Microsoft Store 설치 → API 키 발급 → 로그인 → 봇 이름 → 봇 시작. 5분.

  • 명령어 목록과 설정 방법

    기본 명령어, 방장 전용 명령어, 채팅에서 바로 만드는 내 명령어, 치환자, 반복 공지.

  • 치지직 출석 체크 봇 설정 방법

    인사말 출석, 하루 기준 시각, 상황별 인사 문구, 다른 봇에서 출석 기록 이어받기.

  • 치지직 후원·구독 감사 인사 자동으로 하기

    치즈 후원, 구독, 구독권 선물에 자동으로 인사하는 설정, 필요한 권한, 문구 예시.

  • 치지직 투표·추첨·돌림판·후원 룰렛 사용법

    기능 창에서 버튼으로 진행, 시청자는 채팅에 번호만. 후원 룰렛 규칙, OBS 오버레이 주소.

  • 카운터·타이머·스톱워치 방송 화면에 띄우기

    데스 카운터, 라면 타이머, 스톱워치를 OBS 브라우저 소스로. 꾸미기 옵션.

  • 채팅 오버레이·신청곡·알림·TTS·TITS 설정 방법

    방송 화면에 채팅과 알림 카드 띄우기, 채팅으로 유튜브 신청곡 받기, 구독·채팅 읽어주기, VTube Studio 아바타에 물건 던지기, 다크 모드.

  • 치지직 채팅봇이 안 될 때 확인할 것

    반응 없음, 권한 빠짐, 봇 계정 연결 끊김, 구독 인사 안 나감, 설정 미반영. 증상별 원인과 해결 순서.

  • 치지직 채팅봇 6종 비교표

    뚜봇·빵떡·한봇·나디아·브이찍·아인을 방식·비용·봇 이름·기능별로. 공식 안내 기준, 아인만 직접 측정.
