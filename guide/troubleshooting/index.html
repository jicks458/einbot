봇을 켰는데 채팅에 아무 반응이 없어요

증상: 아인 창에는 "봇이 실행 중입니다"로 표시되지만 봇이 응답하지 않습니다.

확인 순서
  1. 설정 → 치지직 연결 맨 위 "지금 상태"의 방송 계정이 실제 방송 채널과 같은지 확인합니다. 다르면 [방송 계정 변경 (다시 로그인)]을 눌러 다시 로그인한 뒤 봇을 다시 시작합니다.
  2. 방송 중인지 확인합니다. 치지직 채팅은 방송 중에만 열립니다.
  3. 명령어 앞에 !를 붙였는지 확인합니다. 기본 출석 인사말은 "안녕하세요"와 "O하"입니다. 처음 설정한 경우 두 번째 인사말은 방송 계정 이름의 첫 글자를 딴 "O하" 형태입니다. 인사말은 설정 → 출석 체크의 "인사말로 출석 처리" 칸에서 확인할 수 있습니다.
  4. 설정 → 이용권에서 무료 체험 또는 이용권 기간이 남아 있는지 확인합니다.
  5. 아인 창에 노란색 안내 띠가 있는지 확인합니다. "○○ 권한이 빠져 …"가 표시되면 다음 항목을, "치지직 로그인이 풀렸습니다"가 표시되면 로그인 항목을 참고합니다.

"권한이 빠졌습니다"라고 나와요

증상: 아인 창에 "○○ 권한이 빠져 …"라는 노란색 안내 띠가 표시되거나, 로그인 완료 화면에 누락된 권한이 표시됩니다.

해결
  1. 설정 → 치지직 연결에서 [방송 계정 변경 (다시 로그인)]을 누릅니다.
  2. 방송 계정으로 로그인하고, 동의 화면의 모든 항목을 선택한 상태로 [동의]를 누릅니다.
  3. 봇이 실행 중이었다면 아인 창에서 [중지]를 누른 뒤 [시작]을 누릅니다.

아인 창에 "치지직 로그인이 풀렸습니다" 안내 띠가 표시되어 있다면 해당 안내 띠를 눌러 다시 로그인할 수도 있습니다.

직접 발급한 키를 사용하는 경우 → 설치 가이드의 내 키 안내

후원 인사는 되는데 구독 인사만 안 나가요

증상: 치즈 후원에는 인사하지만 구독에는 인사하지 않습니다.

확인
  1. 시청자가 구독 후 "기념 메시지"를 채팅에 올렸는지 확인합니다. 구독 인사는 이 메시지가 올라왔을 때만 전송됩니다.
  2. 설정 → 구독·선물 인사에서 "구독·선물 인사 사용"이 켜져 있는지 확인합니다.

자세한 조건은 후원·구독·팔로우 인사 가이드에서 확인할 수 있습니다.

"봇 계정 연결 끊김" 알림이 떠요

증상: 아인 창 위쪽에 노란색 안내 띠가 표시되고, 봇이 봇 이름이 아닌 다른 이름으로 응답합니다.

해결
  1. 휴대폰 등 다른 기기에서 봇 계정을 로그아웃합니다.
  2. 설정 → 봇 계정에서 [봇 계정으로 로그인]을 눌러 봇 계정으로 로그인하고 [로그인 상태 유지]를 켭니다. 화면 안내는 설치 가이드의 "봇 이름 정하기"에서 확인할 수 있습니다. 아인 창의 노란색 안내 띠를 눌러도 봇 계정 로그인 창이 바로 열립니다.
  3. 봇이 실행 중이었다면 아인 창에서 [중지]를 누른 뒤 [시작]을 누릅니다.

봇 계정의 비밀번호를 변경하거나, 네이버 보안설정에서 [모든 기기 로그아웃]을 실행하거나, 봇을 몇 주 이상 켜지 않으면 연결이 끊어질 수 있습니다. 봇을 꾸준히 사용하면 로그인 상태가 자동으로 유지됩니다.

네이버의 "새로운 기기 로그인" 알림은 아인이 이 컴퓨터에서 봇 계정으로 로그인한 기록입니다. [로그아웃]을 누르지 마시기 바랍니다.

안내 띠의 두 번째 줄이 "봇을 껐다 켜면 적용됩니다."라면 봇 계정은 이미 다시 로그인된 상태입니다. 아인 창에서 [중지]를 누른 뒤 [시작]만 누르면 됩니다.

아인 창에 회색 안내 띠 "로그인 상태 유지 없이 로그인됐습니다"가 표시되면, 안내 띠를 눌러 [로그인 상태 유지]를 켠 뒤 다시 로그인합니다.

봇 이름이 아니라 "아인 봇"으로 대답해요

증상: 부계정을 연결했는데 채팅에 봇 이름 대신 "아인 봇" 이름으로 응답이 표시됩니다.

확인
  1. 방송 시작 전이라면 정상일 수 있습니다. 상태 카드에 "방송을 켜면 봇 계정 이름으로 응답"이나 "방송 계정 이름으로 응답"이 표시되더라도, 방송을 시작하면 1분 이내에 봇 이름으로 바뀝니다. 방송 시작 전에는 봇 계정 연결을 10분에 한 번만 시도합니다(버전 2.8.0부터).
  2. 봇이 실행 중인 상태에서 부계정을 연결했다면 아인 창에서 [중지]를 누른 뒤 [시작]을 누릅니다.
  3. "봇 계정 연결 끊김" 안내 띠가 있으면 위 항목에 따라 다시 로그인합니다.
  4. 부계정을 연결한 적이 없다면 "아인 봇"이 정상입니다. 설치 가이드의 "봇 이름 정하기"부터 진행합니다.

직접 발급한 키를 사용하는 경우에는 "아인 봇" 대신 방송 계정 이름으로 응답이 표시됩니다.

봇 계정 프로필 사진이 아인 그림으로 바뀌었어요

증상: 봇 계정의 치지직 프로필 사진이 아인 기본 그림으로 바뀌어 있습니다.

부계정을 처음 연결할 때 프로필 사진이 없으면 아인이 기본 그림을 등록합니다. 봇 채널 소개에는 "아인으로 만든 봇 · einbot.kr" 한 줄이 추가됩니다.

변경 방법
  1. 원하는 그림을 사용하려면 부계정으로 치지직에 로그인해 프로필 사진을 변경합니다. 아인은 직접 등록한 사진을 변경하지 않습니다. 이 경우 설정의 "아인 기본 그림 넣기" 항목도 자동으로 꺼집니다(봇의 다음 확인 시점, 최대 6시간 이내).
  2. 기본 그림을 사용하지 않으려면 설정 → 봇 계정 → 봇 채널 소개에서 "아인 기본 그림 넣기"를 끄고 [저장]을 누릅니다. 소개 한 줄은 같은 화면에서 끄거나 치지직에서 해당 줄을 삭제합니다(치지직에서 삭제하면 설정 항목도 봇의 다음 확인 시점에 자동으로 꺼집니다. 최대 6시간 이내).
  3. 봇이 실행 중이라면 1분 이내에 적용됩니다.

구독권 선물 인사가 안 나가요

증상: 구독·후원 인사는 전송되지만, 구독권 선물에는 인사하지 않습니다.

확인
  1. 방송 중에 봇을 켠 뒤 들어온 선물인지 확인합니다. 선물 인사는 채팅에 표시되는 선물 안내를 기준으로 전송됩니다.
  2. 설정 → 구독·선물 인사에서 "구독·선물 인사 사용"이 켜져 있는지 확인합니다.
  3. 그래도 해결되지 않으면 선물이 들어온 시각과 함께 문의하시기 바랍니다.

팔로우 인사·팔로우 알림이 안 나와요

증상: 기능을 켜 두었는데 팔로우해도 채팅과 방송 화면에 아무것도 표시되지 않습니다.

확인
  1. 두 기능 모두 기본으로 꺼져 있습니다. 설정 → 팔로우 인사와 기능 창 → 알림 오버레이의 "팔로우"를 켰는지 확인합니다.
  2. 봇 계정을 내 채널의 채널 관리자로 지정했는지 확인합니다.
  3. "봇 계정 로그인이 풀려 …" 안내 띠가 있으면 설정 → 봇 계정에서 다시 로그인한 뒤 봇을 다시 시작합니다.
  4. 알림은 방송 중에 새로 팔로우한 계정에 대해서만 한 번 표시됩니다. 테스트는 방송 전에 팔로우하지 않았고 아인이 알린 적도 없는 계정으로, 방송을 시작하고 1분 후에 진행합니다.

인사가 두 번 나가요

증상: 출석 인사나 후원 인사가 두 번 전송됩니다.

확인
  1. 다른 채팅봇과 함께 사용하면 두 봇이 각각 인사합니다. 한쪽 봇에서 해당 기능을 끕니다.
  2. 압축 파일로 설치했던 이전 버전의 아인이 남아 있으면 두 프로그램이 함께 실행될 수 있습니다. 예전 설치본 정리를 참고합니다.

다른 봇의 출석 기록을 옮기는 방법은 출석 가이드에서 확인할 수 있습니다.

설정을 바꿨는데 반영이 안 돼요

증상: 문구나 명령어를 변경했는데 봇이 이전 내용으로 응답합니다.

확인
  1. 설정 창 아래의 [저장]을 눌렀는지 확인합니다. "저장했습니다"가 표시되면 봇을 다시 시작하지 않아도 바로 적용됩니다.
  2. 연결 방식·방송 계정·봇 계정을 변경했다면 아인 창에서 [중지]를 누른 뒤 [시작]을 누릅니다.

[기능] 버튼을 눌러도 창이 안 열려요

증상: "봇을 먼저 시작하세요" 또는 "기능 창을 아직 열 수 없습니다"가 표시됩니다.

확인
  1. 아인 창 상태 카드가 "봇이 실행 중입니다"인지 확인합니다. 기능 창은 봇이 실행 중일 때만 열립니다.
  2. 봇을 방금 켰다면 몇 초 후 [기능]을 다시 누릅니다.
  3. 그래도 열리지 않으면 8391~8395 포트를 사용하는 다른 프로그램을 종료한 뒤 봇을 다시 시작합니다.

기능 창이 보이지 않으면 [기능]을 다시 누릅니다.

기능 창 왼쪽 목록에 원하는 기능이 보이지 않으면 → 목록 맨 아래 [숨긴 기능 N개]를 펼쳐 선택하거나, [목록 편집]에서 해당 기능을 다시 체크한 뒤 [완료]를 누릅니다([기본값으로]를 누르면 모든 기능이 표시됩니다).

OBS에 오버레이가 안 보여요

증상: 브라우저 소스를 추가했는데 화면에 아무것도 표시되지 않습니다.

확인
  1. 봇이 실행 중인지 확인합니다.
  2. 포트가 바뀌었을 수 있으므로 기능 창의 [URL 복사]로 주소를 다시 복사해 입력합니다.
  3. 돌림판은 회전할 때만 표시됩니다. 항상 표시하려면 주소 끝에 ?hidden=0을 붙입니다.
  4. 브라우저 소스 속성의 "보이지 않을 때 소스 종료"를 끕니다.
  5. 업데이트 후에는 오버레이가 몇 초 안에 자동으로 새로고침됩니다. 그래도 이전 모양이 표시되면 소스 속성에서 새로고침합니다.

채팅 오버레이에 채팅이 안 올라와요

증상: 예시 채팅만 계속 표시되거나, 아무것도 표시되지 않습니다.

확인
  1. 봇이 실행 중인지 확인합니다. 예시 채팅은 첫 채팅이 들어오기 전까지만 표시됩니다.
  2. 봇을 다시 시작했다면 OBS 소스 속성에서 새로고침합니다.
  3. CSS를 직접 입력했다면 기능 창 → 채팅 오버레이의 [비우기]를 누른 뒤 다시 확인합니다. CSS 입력 방법은 화면·소리 가이드에서 확인할 수 있습니다.

알림 소리가 안 나요

증상: 알림 카드는 표시되지만 소리가 나지 않거나, 방송에 소리가 송출되지 않습니다.

확인
  1. 알림 소리는 기본으로 꺼져 있습니다. 기능 창 → 알림 오버레이에서 "알림 소리"를 켜고 [저장]을 눌렀는지 확인합니다.
  2. "소리 낼 알림"에서 해당 알림 종류가 켜져 있는지 확인합니다. 후원 알림 소리는 기본으로 꺼져 있습니다.
  3. OBS에서 소리가 나는지는 [테스트]로 확인합니다. [들어 보기]는 기능 창에서만 들립니다.
  4. 브라우저 소스의 "OBS를 통해 오디오 제어"를 켰다면 오디오 믹서에서 해당 소스의 음량을 높입니다.

TTS 소리가 안 나요 / 방송에 안 나가요

증상: [테스트 읽기]를 눌러도 소리가 나지 않거나, 방송에 소리가 송출되지 않습니다.

확인
  1. 기능 창 → TTS 읽어주기에서 "TTS 사용"이 켜져 있는지 확인합니다. TTS는 기본으로 꺼져 있습니다.
  2. 소리는 Windows 기본 출력 장치로 출력됩니다. OBS 데스크톱 오디오가 해당 장치로 설정되어 있는지 확인합니다.
  3. Windows 설정 → 시간 및 언어 → 음성에 한국어 음성이 있는지 확인합니다.
  4. 읽을 채팅이 많이 밀려 있다면 [읽기 중지]를 누르거나 "밀림 허용" 값을 줄입니다.

TITS가 "연결되지 않음"이에요

증상: "TITS 연동 사용"을 켰는데 배지가 "연결되지 않음. TITS를 켜고 설정에서 API를 켜세요"에서 바뀌지 않습니다.

확인
  1. TITS가 실행 중이고, TITS 설정(오른쪽 아래 톱니바퀴)의 API가 "Enabled ON"인지 확인합니다.
  2. TITS의 API 포트(기본 42069)와 기능 창의 포트가 같은지 확인합니다.
  3. 설정을 수정한 뒤 15초 정도 기다립니다. 아인은 15초마다 다시 연결을 시도합니다.

아이템을 던져도 아바타에 변화가 없으면 TITS 왼쪽 목록에서 VTube Studio 연결 상태(✓)를 확인합니다.

후원 룰렛을 껐는데 돌아요 / 켜지 않았는데 돌아요

증상: 기능을 끄고 저장했는데 결과가 계속 전송되거나, 켠 적이 없는데 후원에 룰렛 결과가 전송됩니다.

확인
  1. 기능 창 → 후원 룰렛의 "후원 룰렛 사용"이 꺼져 있는지 확인합니다.
  2. 기능을 끄면 이후 들어오는 후원부터 룰렛이 실행되지 않습니다. 이미 들어온 후원은 룰렛이 끝까지 실행되고 결과도 전송됩니다.
  3. 저장 후 "저장했습니다"가 표시되었는지 확인합니다. 표시되지 않았다면 기능 창을 닫고 [기능]으로 다시 연 뒤 저장합니다.

출석부에 시청자가 안 나와요 / OBS 독이 비어 있어요

증상: 방송 중인데 기능 창 → 출석부나 OBS 독에 채팅한 시청자가 표시되지 않습니다.

확인
  1. 출석부 아래 [출석부 사용]이 켜져 있는지 확인합니다. 꺼져 있는 동안에는 기록을 모으지 않습니다.
  2. 채팅한 시청자만 표시됩니다. 채팅 없이 시청만 한 시청자는 치지직이 정보를 제공하지 않아 표시되지 않습니다.
  3. 방송 계정과 봇 계정(부계정·"아인 봇")의 채팅은 포함하지 않습니다. 내 계정으로 채팅을 입력했을 때 표시되지 않는 것은 정상입니다.
  4. "목록에서 뺀 사람"에 해당 시청자가 있는지 확인합니다. 있다면 [되돌리기]를 누릅니다.
  5. OBS 독에 "봇과 연결이 끊겼습니다" 안내 띠가 있으면 아인 창에서 봇이 실행 중인지 확인합니다. 봇이 실행되면 다시 연결됩니다. OBS를 봇보다 먼저 실행했다면 독 안을 클릭한 뒤 Ctrl+R을 눌러 새로고침합니다.

출석부는 OBS의 브라우저 소스가 아닌 브라우저 독에 추가합니다. 추가하는 방법은 출석 가이드의 출석부에서 확인할 수 있습니다.

"치지직 로그인이 풀렸습니다" 띠가 떠요 / 초기 설정 화면이 다시 열려요

증상: 아인 창에 노란색 안내 띠가 표시되고 상태 카드에 "로그인이 필요합니다"가 표시됩니다.

해결
  1. 안내 띠나 [시작]을 누르면 설정 창의 치지직 연결 화면이 열립니다. [방송 계정 변경 (다시 로그인)]을 누릅니다.
  2. 방송 계정으로 로그인하고, 동의 화면(로그인 방식으로 사용하는 경우 앱 이름 "아인 채팅봇")의 모든 항목을 선택한 상태로 [동의]를 누릅니다. 항목을 선택하지 않으면 "연동은 됐지만, 권한이 부족해요"가 표시될 수 있습니다.
  3. 안내 띠가 사라지면 해결된 것입니다. 봇이 꺼져 있으면 [시작]을 누릅니다.

"초기 설정" 화면이 다시 열렸다면 안내에 따라 방송 계정으로 다시 로그인합니다. 출석 기록과 설정은 그대로 유지됩니다. 봇 계정을 사용하던 경우에는 봇 이름 화면을 그대로 건너뛰거나, [다른 봇 계정으로 바꿀게요]를 눌러 다시 로그인합니다.

"치지직 연결이 새로 바뀌었습니다" 띠가 떠요

증상: 아인 창 위쪽에 노란색 안내 띠가 표시되며, 봇은 아직 응답합니다.

해결
  1. 안내 띠를 바로 누릅니다. 설정 창의 치지직 연결 화면이 열립니다. 이 절차를 미루면 봇의 응답이 중지되고 로그인 풀림 안내 띠로 바뀝니다.
  2. [방송 계정 변경 (다시 로그인)]을 누르고 방송 계정으로 로그인합니다. 동의 화면(앱 이름 "아인 채팅봇")이 표시되면 모든 항목을 선택한 상태로 [동의]를 누릅니다.
  3. 안내 띠가 사라지면 해결된 것입니다. 봇이 실행 중이었다면 "봇을 껐다 켜야 적용됩니다" 안내 띠가 표시됩니다. 아인 창에서 [중지]를 누른 뒤 [시작]을 누릅니다.

봇의 응답은 부계정이 있으면 부계정 이름으로, 없으면 "아인 봇" 이름으로 표시됩니다.

안내 띠가 보이지 않으면 [시작]을 누릅니다. 로그인 풀림 안내 띠나 "설정이 필요합니다"가 표시되면, 안내 띠나 [시작]을 한 번 더 눌러 다시 로그인합니다. 컴퓨터를 켠 뒤에도 아인이 보이지 않으면 시작 메뉴에서 아인을 실행합니다.

"봇을 껐다 켜야 적용됩니다" 띠가 떠요

증상: 아인 창에 "방송 계정을 다시 로그인했습니다. 봇을 껐다 켜야 적용됩니다."라는 노란색 안내 띠가 표시됩니다.

해결
  1. 아인 창에서 [중지]를 누릅니다.
  2. [시작]을 누릅니다. 안내 띠가 사라지면 해결된 것입니다.

봇이 실행 중인 상태에서 설정 → 치지직 연결에서 다시 로그인하면 이 안내 띠가 표시됩니다.

로그인하다가 하얀 화면에서 멈춰요

증상: 직접 발급한 키를 사용하는 중에 로그인 마지막 단계에서 하얀 화면만 표시됩니다.

해결
  1. 로그인 방식으로 돌아가려면 설정 → 치지직 연결의 "연결 방식"을 펼쳐 두 칸을 비운 뒤 [저장]을 누릅니다.
  2. 같은 화면의 [방송 계정 변경 (다시 로그인)]을 눌러 로그인합니다.
  3. 키를 계속 사용하려면 Client ID와 Client Secret을 앞뒤 공백 없이 다시 붙여 넣습니다.
  4. 개발자 센터의 로그인 리디렉션 URL이 http://localhost:3000/callback인지 확인합니다.

키 값이 올바르지 않을 때 발생하는 증상입니다.

무료 체험이 끝났다고 나와요

증상: 무료 체험 또는 이용권 기간이 끝났다는 안내 띠가 표시되고 봇이 시작되지 않습니다.

해결
  1. 스마트스토어에서 이용권(1개월 2,900원부터)을 구매합니다.
  2. 주문번호는 스마트스토어 → 주문/배송 조회(구매내역)에서 복사합니다.
  3. 설정 → 이용권의 "주문번호 등록" 칸에 주문번호를 붙여 넣고 [등록]을 누릅니다. 연장 코드는 "연장 코드 등록" 칸에 입력합니다.
  4. 봇을 시작합니다. 출석 기록과 설정은 그대로 유지됩니다.
등록되지 않을 때
  1. 주문번호를 앞뒤 공백 없이, 하이픈을 포함해 그대로 입력했는지 확인합니다.
  2. 결제 직후라면 몇 분 후 다시 [등록]을 누릅니다.
  3. 이전에 등록한 적이 있는 주문번호라면, 등록할 때 사용한 방송 계정으로 로그인했는지 확인합니다.

주문번호를 입력해도 등록되지 않으면 주문번호와 함께 메일로 문의하시기 바랍니다.

창을 닫아도 봇이 계속 돌아요

증상: 아인 창의 X를 눌렀는데 봇이 계속 응답하고, 작업 표시줄에서도 아인이 사라졌습니다.

창을 닫으면 아인은 작업 표시줄 오른쪽의 알림 영역으로 이동하며, 봇은 계속 실행됩니다.

봇을 끄려면
  1. 아인 창 상태 카드의 [중지]를 누릅니다.
  2. 앱을 완전히 종료하려면 알림 영역의 아인 아이콘을 마우스 오른쪽 버튼으로 클릭한 뒤 [앱 종료]를 선택합니다.

컴퓨터를 켜면 아인이 저절로 켜져요 (자동 시작 끄기·켜기)

증상: 컴퓨터를 켜면 창은 표시되지 않지만 알림 영역에 아인이 있고, 봇이 실행 중입니다.

컴퓨터를 켤 때 아인이 창 없이 실행되는 자동 시작 기능입니다.

끄거나 다시 켜려면
  1. 설정 → 문제 해결·앱 삭제의 "컴퓨터를 켜면 아인과 봇을 자동으로 켜기"를 끄거나 켠 뒤 [저장]을 누릅니다. 버전 2.7.0까지는 이 항목이 설정 → 기본 설정에 있었습니다.
  2. Windows 설정 → 앱 → 시작 프로그램의 "아인"에서도 끄고 켤 수 있습니다. 이곳에서 끈 경우에는 다시 켤 때도 이곳에서 켜야 합니다.

아인이 잠깐 꺼졌다 켜졌어요 (자동 업데이트)

증상: 아인이 잠깐 사라졌다 다시 나타났고, "…으로 업데이트됐습니다" 안내 띠가 표시됩니다.

아인은 방송하지 않을 때 새 버전을 자동으로 설치하고 다시 실행합니다. 봇이 중지되는 시간은 10초 내외입니다.

알아 둘 것
  1. 방송 중이거나, 아인 창을 사용하는 중이거나, 설정 창이 열려 있으면 설치를 미룹니다.
  2. "새 버전(…)이 나왔습니다" 안내 띠가 표시되면 안내 띠를 누릅니다. 이 안내 띠는 자동 설치에 실패했을 때 표시됩니다.
  3. 버전 2.1.1 이하는 Microsoft Store가 아인을 완전히 종료한 뒤에 설치합니다. 알림 영역에서 [앱 종료]를 선택한 다음 Microsoft Store 앱 → 라이브러리 → [업데이트 받기]를 누릅니다.
  4. "…을 받아 두었습니다" 안내 띠가 아인을 다시 시작한 뒤에도 사라지지 않는 경우나, 업데이트 기록에 올라온 새 버전이 이틀이 지나도 설치되지 않는 경우에는 Microsoft Store에서 직접 업데이트합니다. 알림 영역에서 [앱 종료]를 선택한 다음 Microsoft Store 앱 → 라이브러리 → [업데이트 받기]를 누릅니다. 업데이트 여부는 아인 창의 버전 번호(v… 형식)에서 확인할 수 있습니다.

변경 사항은 업데이트 기록에서 확인할 수 있습니다.
