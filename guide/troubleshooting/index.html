봇을 켰는데 채팅에 아무 반응이 없어요

증상: 아인 창은 "봇이 실행 중입니다"인데 봇이 답하지 않습니다.

확인 순서
  1. 설정 → 치지직 연결의 "지금 연결된 방송 계정"이 방송 채널인지 봅니다. 다르면 [방송 계정 변경 (다시 로그인)]으로 다시 로그인하고 봇을 껐다 켭니다.
  2. 방송 중인지 봅니다. 치지직 채팅은 방송 중에만 열립니다.
  3. 명령어 앞에 !를 붙였는지 봅니다. 출석 인사말은 기본 "안녕하세요", "O하"입니다.
  4. 체험·이용권 기간이 남았는지 설정 → 이용권에서 봅니다.
  5. 아인 창에 "○○ 권한이 빠져 …" 노란 띠가 있으면 다음 항목을 봅니다.

"권한이 빠졌습니다"라고 나와요

증상: 아인 창에 "○○ 권한이 빠져 …" 노란 띠가 뜨거나, 로그인 완료 화면에 빠진 권한이 나옵니다.

해결
  1. 설정 → 치지직 연결에서 [방송 계정 변경 (다시 로그인)]을 누릅니다.
  2. 방송 계정으로 로그인하고, 동의 화면의 항목을 모두 켠 채 [동의]를 누릅니다.
  3. 봇이 켜져 있었다면 아인 창에서 [중지] 뒤 [시작]을 누릅니다.

직접 발급한 키로 쓰는 분 → 설치 가이드의 API 키 안내

후원 인사는 되는데 구독 인사만 안 나가요

증상: 치즈 후원에는 인사하는데 구독이 들어와도 조용합니다.

확인
  1. 시청자가 구독 뒤 "기념 메시지"를 채팅에 올렸는지 봅니다. 구독 인사는 그 메시지에만 나갑니다.
  2. 설정 → 구독·선물 인사에서 "구독·선물이 오면 자동으로 인사"가 켜져 있는지 봅니다.

자세한 조건은 후원·구독·팔로우 인사 가이드에 있습니다.

"봇 계정 연결 끊김" 알림이 떠요

증상: 아인 창 위에 노란 띠가 뜨고, 봇이 내 이름으로 답합니다.

해결
  1. 휴대폰 등 다른 기기에서 부계정을 로그아웃합니다.
  2. 설정 → 봇 계정에서 [봇 계정으로 로그인]을 눌러 부계정으로 로그인합니다. 화면은 설치 가이드의 "봇 이름 정하기"에 있습니다.
  3. 봇이 켜져 있었다면 아인 창에서 [중지] 뒤 [시작]을 누릅니다.

네이버의 "새로운 기기 로그인" 알림은 봇입니다. [로그아웃]을 누르지 마세요.

봇 이름이 아니라 내 이름으로 대답해요

증상: 부계정을 연결했는데 채팅에 내 닉네임으로 답이 올라옵니다.

확인
  1. 방송 전이면 정상입니다. 상태 카드가 "방송 계정 이름으로 응답"이어도 방송을 시작하면 봇 이름으로 바뀝니다.
  2. 봇이 켜진 채로 부계정을 연결했다면 아인 창에서 [중지] 뒤 [시작]을 누릅니다.
  3. "봇 계정 연결 끊김" 띠가 있으면 위 항목대로 다시 로그인합니다.
  4. 부계정을 연결한 적이 없다면 설치 가이드의 "봇 이름 정하기"부터 합니다.

봇 계정 프로필 사진이 아인 그림으로 바뀌었어요

증상: 봇 계정의 치지직 프로필 사진이 아인 기본 그림으로 되어 있습니다.

부계정을 처음 연결할 때 사진이 없으면 아인이 기본 그림을 넣습니다. 봇 채널 소개에는 "아인으로 만든 봇 · einbot.kr" 한 줄을 넣습니다.

바꾸려면
  1. 내 그림을 쓰려면 부계정으로 치지직에 들어가 프로필 사진을 바꿉니다. 아인은 그 사진을 바꾸지 않습니다.
  2. 빼려면 설정 → 봇 계정 → 봇 채널 소개에서 "아인 기본 그림 넣기"를 끄고 [저장]합니다. 소개 한 줄도 같은 곳에서 끕니다.
  3. 봇이 켜져 있으면 1분 안에 반영됩니다.

구독권 선물 인사가 안 나가요

증상: 구독·후원 인사는 되는데, 구독권 선물에는 인사가 없습니다.

확인
  1. 방송 중, 봇을 켠 뒤에 들어온 선물인지 봅니다. 선물 인사는 채팅에 뜨는 선물 안내를 보고 나갑니다.
  2. 설정 → 구독·선물 인사에서 "구독·선물이 오면 자동으로 인사"가 켜져 있는지 봅니다.
  3. 그래도 안 되면 선물이 들어온 시각과 함께 문의해 주세요.

팔로우 인사·팔로우 알림이 안 나와요

증상: 켜 두었는데 팔로우해도 채팅과 방송 화면에 아무것도 나오지 않습니다.

확인
  1. 둘 다 처음에는 꺼져 있습니다. 설정 → 팔로우 인사와 기능 창 → 알림 오버레이의 "팔로우"를 켰는지 봅니다.
  2. 봇 계정을 내 채널의 채널 관리자로 지정했는지 봅니다.
  3. "봇 계정 로그인이 풀려 …" 띠가 있으면 설정 → 봇 계정에서 다시 로그인하고 봇을 껐다 켭니다.
  4. 방송 중에 새로 팔로우한 계정만 한 번 알립니다. 시험은 방송 전에 팔로우하지 않았고 알린 적도 없는 계정으로, 방송을 켜고 1분 뒤에 합니다.

인사가 두 번 나가요

증상: 출석 인사나 후원 인사가 두 번 올라옵니다.

확인
  1. 다른 채팅봇과 같이 쓰면 두 봇이 각자 인사합니다. 한쪽에서 그 기능을 끕니다.
  2. 압축 파일로 설치했던 옛 아인이 남아 있으면 둘이 같이 돌 수 있습니다. 예전 설치본 정리를 봅니다.

다른 봇의 출석 기록을 옮기는 법은 출석 가이드에 있습니다.

설정을 바꿨는데 반영이 안 돼요

증상: 문구나 명령어를 바꿨는데 봇은 예전 그대로 답합니다.

확인
  1. 설정 창 아래의 [저장]을 눌렀는지 봅니다. "저장했습니다"가 뜨면 봇이 켜진 채로 바로 반영됩니다.
  2. API 키·방송 계정·봇 계정을 바꿨다면 아인 창에서 [중지] 뒤 [시작]을 누릅니다.

[기능] 버튼을 눌러도 창이 안 열려요

증상: "봇을 먼저 시작하세요" 또는 "기능 창을 아직 열 수 없습니다"가 뜹니다.

확인
  1. 아인 창 상태 카드가 "봇이 실행 중입니다"인지 봅니다. 기능 창은 봇이 켜져 있을 때만 열립니다.
  2. 봇을 막 켰다면 몇 초 뒤 [기능]을 다시 누릅니다.
  3. 그래도 안 되면 8391~8395 포트를 쓰는 다른 프로그램을 끄고 봇을 껐다 켭니다.

창을 잃어버렸으면 [기능]을 다시 누르세요.

OBS에 오버레이가 안 보여요

증상: 브라우저 소스를 넣었는데 화면이 비어 있습니다.

확인
  1. 봇이 켜져 있는지 봅니다.
  2. 주소는 기능 창의 [URL 복사]로 넣습니다. 포트가 바뀌었을 수 있으니 다시 복사해 봅니다.
  3. 돌림판은 돌 때만 보입니다. 늘 보이게 하려면 주소 끝에 ?hidden=0을 붙입니다.
  4. 브라우저 소스 속성의 "보이지 않을 때 소스 종료"를 끕니다.
  5. 업데이트 뒤에는 오버레이가 몇 초 안에 스스로 새로 고칩니다. 그래도 예전 모양이면 소스 속성에서 새로 고침합니다.

채팅 오버레이에 채팅이 안 올라와요

증상: 예시 채팅만 계속 보이거나, 아무것도 안 보입니다.

확인
  1. 봇이 켜져 있는지 봅니다. 예시 채팅은 첫 채팅이 오기 전까지만 보입니다.
  2. 봇을 껐다 켰다면 OBS 소스 속성에서 새로 고침합니다.
  3. CSS를 직접 넣었다면 기능 창 → 채팅 오버레이의 [비우기]를 누르고 다시 봅니다. 넣는 법은 화면·소리 가이드에 있습니다.

알림 소리가 안 나요

증상: 알림 카드는 뜨는데 소리가 없거나, 방송에는 소리가 안 나갑니다.

확인
  1. 알림 소리는 처음에는 꺼져 있습니다. 기능 창 → 알림 오버레이에서 "알림 소리"를 켜고 [저장]했는지 봅니다.
  2. "소리 낼 알림"에서 그 종류가 켜져 있는지 봅니다. 후원은 처음에 꺼져 있습니다.
  3. OBS에서 들리는지는 [테스트]로 봅니다. [들어 보기]는 기능 창에서만 들립니다.
  4. 브라우저 소스의 "OBS를 통해 오디오 제어"를 켰다면 오디오 믹서에서 그 소스의 음량을 올립니다.

TTS 소리가 안 나요 / 방송에 안 나가요

증상: [테스트 읽기]를 눌러도 조용하거나, 방송에는 소리가 안 나갑니다.

확인
  1. 기능 창 → TTS 읽어주기에서 "TTS 사용"이 켜져 있는지 봅니다. 처음에는 꺼져 있습니다.
  2. 소리는 Windows 기본 출력 장치로 나갑니다. OBS 데스크톱 오디오가 그 장치를 잡고 있는지 봅니다.
  3. Windows 설정 → 시간 및 언어 → 음성에 한국어 음성이 있는지 봅니다.
  4. 채팅이 밀렸다면 [읽기 중지]를 누르거나 "밀림 허용" 값을 줄입니다.

TITS가 "연결되지 않음"이에요

증상: "TITS 연동 사용"을 켰는데 배지가 "연결되지 않음. TITS를 실행하세요"에서 바뀌지 않습니다.

확인
  1. TITS가 켜져 있고, TITS 설정(오른쪽 아래 톱니바퀴)의 API가 "Enabled ON"인지 봅니다.
  2. TITS의 API 포트(기본 42069)와 기능 창의 포트가 같은지 봅니다.
  3. 고친 뒤 15초쯤 기다립니다. 아인이 15초마다 다시 연결합니다.

던져도 아바타가 그대로면 TITS 왼쪽 목록에서 VTube Studio 연결(✓)을 봅니다.

후원 룰렛을 껐는데 돌아요 / 켜지 않았는데 돌아요

증상: 끄고 저장했는데 결과가 또 나오거나, 켠 적 없는데 후원에 결과가 나옵니다.

확인
  1. 기능 창 → 후원 룰렛의 "후원 룰렛 사용"이 꺼져 있는지 봅니다.
  2. 끄면 새 후원부터 멈춥니다. 이미 들어온 후원은 마저 돌고 결과도 나갑니다.
  3. 저장 뒤 "저장했습니다"가 떴는지 봅니다. 안 떴다면 기능 창을 닫고 [기능]으로 다시 열어 저장합니다.

초기 설정 화면이 다시 열려요

증상: 잘 쓰던 아인을 켰는데 "초기 설정" 화면이 다시 나옵니다.

해결
  1. 안내대로 방송 계정으로 다시 로그인합니다. API 키를 새로 받을 필요는 없습니다.
  2. 출석 기록과 명령어·문구 설정은 그대로 남아 있습니다.

치지직 연결 방식이나 API 키를 바꿨거나, 치지직 로그인이 만료되면 이 화면이 나옵니다.

로그인하다가 하얀 화면에서 멈춰요

증상: 직접 발급한 키로 쓰는데, 로그인 마지막 단계에서 하얀 화면만 나옵니다.

해결
  1. 키 없이 쓰려면 설정 → 치지직 연결에서 키 두 칸을 비우고 [저장]합니다.
  2. 같은 화면의 [방송 계정 변경 (다시 로그인)]으로 로그인합니다.
  3. 키를 계속 쓰려면 Client ID와 Client Secret을 앞뒤 공백 없이 다시 붙여 넣습니다.
  4. 개발자 센터의 로그인 리디렉션 URL이 http://localhost:3000/callback인지 봅니다.

키 값이 틀리면 생기는 증상입니다.

무료 체험이 끝났다고 나와요

증상: 체험이나 이용권이 끝났다는 띠가 뜨고 봇이 켜지지 않습니다.

해결
  1. 스마트스토어에서 이용권을 삽니다. 1개월 2,900원부터입니다.
  2. 설정 → 이용권의 "주문번호 등록" 칸에 주문번호를 붙여 넣고 [등록]을 누릅니다. 연장 코드는 "연장 코드 등록" 칸에 넣습니다.
  3. 봇을 시작합니다. 출석 기록과 설정은 그대로입니다.

주문번호를 넣어도 안 되면 주문번호와 함께 메일로 문의해 주세요.

창을 닫아도 봇이 계속 돌아요

증상: 아인 창의 X를 눌렀는데 봇이 계속 답하고, 작업 표시줄에서도 사라졌습니다.

창을 닫으면 아인은 작업 표시줄 오른쪽 알림 영역으로 숨고, 봇은 계속 돌아갑니다.

봇을 끄려면
  1. 아인 창 상태 카드의 [중지]를 누릅니다.
  2. 앱까지 끄려면 알림 영역의 아인 아이콘을 오른쪽 버튼으로 눌러 [앱 종료]를 고릅니다.

컴퓨터를 켜면 아인이 저절로 켜져요 (자동 시작 끄기·켜기)

증상: 컴퓨터를 켜니 창은 없는데 알림 영역에 아인이 있고, 봇이 켜져 있습니다.

컴퓨터를 켤 때 아인이 창 없이 켜지는 자동 시작입니다.

끄거나 다시 켜려면
  1. 설정 → 기본 설정의 "컴퓨터를 켜면 아인과 봇을 자동으로 켜기"를 끄고(또는 켜고) [저장]합니다.
  2. Windows 설정 → 앱 → 시작 앱의 "아인"으로도 끄고 켤 수 있습니다. 여기서 껐다면 켤 때도 여기서 켭니다.

아인이 잠깐 꺼졌다 켜졌어요 (자동 업데이트)

증상: 아인이 잠깐 사라졌다 다시 나타났고, "…으로 업데이트됐습니다" 띠가 보입니다.

아인은 방송하지 않을 때 새 버전을 스스로 설치하고 다시 켜집니다. 봇이 멈추는 시간은 10초 안팎입니다.

알아 둘 것
  1. 방송 중이거나, 아인 창을 보고 있거나, 설정 창이 열려 있으면 설치를 미룹니다.
  2. "새 버전(…)이 나왔습니다" 띠가 뜨면 띠를 누릅니다. 스스로 설치하지 못했을 때 뜹니다.

바뀐 내용은 업데이트 기록에 있습니다.

아인을 지우려면

제거하면 설정과 출석 기록도 함께 지워집니다. 출석 기록을 남기려면 1·2번을 먼저 하세요.

지우는 순서
  1. 설정 → 문제 해결·앱 삭제에서 [로그 폴더 열기]를 누릅니다.
  2. 열린 폴더(logs)의 한 단계 위인 data 폴더를 다른 곳에 복사해 둡니다.
  3. 같은 화면의 [앱 삭제]를 누르면 Windows 앱 목록이 열립니다.
  4. 목록에서 "아인"을 찾아 [제거]를 누릅니다.

다른 컴퓨터로 옮기려면 지우기 전에 문의해 주세요.

Microsoft Store에서 설치가 안 돼요

증상: 설치 버튼이 반응하지 않거나, Store 앱이 열리지 않습니다.

확인
  1. Windows 10 이상인지 봅니다. Windows 업데이트가 밀려 있으면 먼저 업데이트합니다.
  2. 회사·학교 PC처럼 Store가 막혀 있으면 einbot.help@gmail.com으로 문의해 주세요. 다른 설치 방법을 알려 드립니다.

그래도 안 되면

디스코드 문의 서버의 [질문] 방이나 einbot.help@gmail.com으로 보내 주세요. 평일 24시간 안에 답합니다.

채널 이름과 일이 생긴 날짜·시각을 적어 주세요. 로그 파일(설정 → 문제 해결·앱 삭제 → [로그 폴더 열기])과 주문번호는 메일로만 보내 주세요.

아인은 오류·사용 횟수·후원 금액 구간 같은 진단 정보를 보냅니다. 채팅 내용·시청자 닉네임·로그인 정보는 보내지 않고, 설정 → 진단 정보에서 끌 수 있습니다. 자세한 것은 개인정보처리방침에 있습니다.
