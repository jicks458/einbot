치지직 채팅봇이 안 될 때 확인할 것

아인을 쓰다가 막히는 상황을 증상별로 모았습니다. 실제로 사용자들이 겪은 일과 그 원인을 기준으로 쓰며, 대부분은 설정 화면에서 한두 번 클릭으로 해결됩니다. 해당 증상을 차례에서 골라 그 부분만 읽으세요.

기준 버전 1.7.2 · 2026년 9월 9일 갱신

차례
  1. 봇을 켰는데 채팅에 아무 반응이 없어요

  5. 봇 이름이 아니라 내 이름으로 대답해요

  7. 설정을 바꿨는데 반영이 안 돼요

봇을 켰는데 채팅에 아무 반응이 없어요

증상: 아인 창은 "실행 중"인데 !출첵을 쳐도, 인사를 해도 봇이 아무 말도 하지 않습니다.

순서대로 확인하세요. 위에 있는 것이 더 흔한 원인입니다.

확인 순서
  1. 방송 채널로 로그인했는지. 아인은 로그인한 계정의 채널에 붙습니다. 봇 이름용 부계정이나 다른 계정으로 로그인하면 그 계정의 (비어 있는) 채널을 지켜보게 되어 아무 반응이 없습니다. 아인 창과 설정 화면에 표시된 연동 채널 이름이 방송 채널인지 보고, 다르면 설정 → [방송 계정 변경]으로 방송 계정에 다시 로그인하세요.
  2. 방송 중인지. 치지직 채팅은 방송 중에만 열립니다. 방송을 켠 뒤 채팅에 명령어를 쳐 보세요.
  3. 명령어 형식. 기본 명령어는 !출첵처럼 앞에 느낌표가 붙습니다. 출석은 설정한 인사말(기본 "안녕하세요")을 쳐야 인식합니다. 명령어 가이드에서 목록을 확인하세요.
  4. 무료 체험·이용권 기간. 기간이 끝나면 봇이 멈춥니다. 아인 창에 남은 기간이 표시되고, 끝났으면 아래 항목을 보세요.
  5. 권한. 아인 창 로그에 "권한이 빠졌습니다"가 있으면 다음 항목입니다.

"권한이 빠졌습니다"라고 나와요

증상: 봇을 켤 때 로그에 빠진 권한 이름이 나오거나, 로그인 완료 화면이 빠진 권한 목록을 보여줍니다.

아인은 치지직 개발자 센터에 등록한 앱의 권한(API Scopes) 4개로 동작합니다. 유저 조회, 채팅 메시지 조회, 채팅 메시지 쓰기는 봇이 뜨는 데 필요하고, 후원 조회는 후원 인사에 필요합니다. 구독 인사와 구독권 선물 인사는 권한이 필요 없습니다. 아인이 정확히 어떤 권한이 빠졌는지 이름을 짚어 알려주고, 1.7.2부터는 아인 창 위에 노란 띠로도 보여주므로 그 항목만 추가하면 됩니다.

해결
  1. 치지직 개발자 센터에서 내 앱을 열고 API Scopes에서 빠진 항목을 체크해 저장합니다. 설치 가이드의 화면 안내를 참고하세요.
  2. 등록 뒤의 권한 변경은 치지직 검수를 거쳐 반영됩니다. 검수가 끝나면 봇을 다시 켜세요. 아인이 로그인 창을 열어 새 권한에 동의를 받습니다.
  3. 로그인 창이 열리지 않으면 설정 → [방송 계정 변경]으로 직접 다시 로그인하면 됩니다.

개발자 센터에서 권한을 바꾸면 "신규 검수가 진행되며 승인까지 이용이 제한된다"는 안내가 나옵니다. 필요한 권한을 한 번에 모두 체크하고, 시험 삼아 권한을 뺐다 넣지 마세요.

후원 인사는 되는데 구독 인사만 안 나가요

증상: 치즈 후원에는 인사하는데 구독이 들어와도 조용합니다.

구독 인사는 시청자가 구독·갱신 뒤 "기념 메시지를 남기시겠습니까?"에 예를 눌러 채팅에 올린 구독 메시지에만 나갑니다. 조용히 구독·갱신한 시청자나 방송 밖 갱신에는 메시지가 없으니 인사도 없는 것이 정상입니다. 시청자가 알리고 싶을 때만 함께 축하하는 방식입니다.

확인
  1. 시청자가 채팅에 구독 메시지를 올렸는데도 조용했는지 확인합니다. 카드가 없었다면 인사가 없는 것이 정상입니다.
  2. 방송 중 채팅이 연결돼 있어야 합니다. 부계정을 쓴다면 "봇 계정 연결 끊김" 알림이 떠 있지 않은지 봅니다.
  3. 설정 → 구독·구독권 선물 감사 인사에서 "구독·선물이 오면 자동으로 인사"가 켜져 있는지 확인합니다.
  4. 앱이 1.7.1 이하라면 "구독 조회" 권한이 필요했던 옛 방식입니다. Microsoft Store에서 업데이트하세요.

후원·구독 인사의 설정과 문구는 후원·구독 인사 가이드에 따로 정리했습니다.

"봇 계정 연결 끊김" 알림이 떠요

증상: 아인 창 위에 노란 배너와 트레이 알림이 뜨고, 봇이 내 이름으로 대답하기 시작합니다.

봇 이름용 부계정의 네이버 로그인이 풀린 것입니다. 가장 흔한 원인은 부계정을 휴대폰 등 다른 기기에서도 쓰는 것입니다. 봇이 접속하면 휴대폰에 "새로운 기기 로그인" 알림이 오는데, 여기서 [로그아웃]이나 [내가 아님]을 누르면 봇의 세션이 바로 끊어집니다. 그 외에 부계정 비밀번호를 바꿨거나 봇을 몇 주 이상 켜지 않았을 때도 생깁니다.

해결
  1. 휴대폰 등 다른 기기에서 부계정을 로그아웃합니다. 부계정은 봇 전용으로 두는 것이 가장 안정적입니다.
  2. 봇을 끄고 설정 → [API 및 봇 계정 설정](또는 [부계정 설정하기])에서 안내대로 브라우저에서 부계정으로 로그인한 뒤 NID_AUT, NID_SES를 다시 복사해 넣고 저장합니다. 화면 순서는 설치 가이드 5단계에 있습니다.
  3. 봇을 시작합니다. "[봇 계정] 연결 완료" 로그가 나오면 끝입니다.

앞으로 휴대폰에 "새로운 기기 로그인" 알림이 오면 그것이 봇입니다. 로그아웃하지 말고 두세요.

봇 이름이 아니라 내 이름으로 대답해요

증상: 부계정을 연결했는데 채팅에는 내 닉네임으로 응답이 올라옵니다.

부계정 연결이 안 된 상태에서 아인이 본인 계정으로 대신 응답하는 것입니다. 두 경우가 있습니다.

  • 방송 전. 치지직 채팅 서버는 방송 중에만 열리므로, 방송 전에 봇을 켜면 로그에 아래처럼 나오는 것이 정상입니다. 방송이 시작되면 자동으로 연결됩니다.

    [봇 계정] 연결 실패 (방송 전이면 정상): …

  • 방송 중에도 계속 내 이름으로 나옴. 부계정 로그인이 풀린 것입니다. 위 항목대로 로그인 정보를 다시 넣으세요. 설정에 부계정을 넣은 적이 없다면 설치 가이드 5단계부터 하면 됩니다.

구독권 선물 인사가 안 나가요

증상: 구독 인사와 후원 인사는 되는데, 누가 구독권을 선물해도 인사가 없습니다.

구독권 선물은 치지직이 공식적으로 알려주지 않아서, 아인이 방송 채팅에 올라오는 "○○님이 구독권 N개를 선물했습니다" 안내를 보고 동작합니다. 그래서 방송 중에 채팅이 연결된 상태여야 하고, 봇을 켠 뒤에 들어온 선물에만 인사합니다.

확인
  1. 봇 이름용 부계정을 쓴다면 "봇 계정 연결 끊김" 알림이 떠 있지 않은지 봅니다. 끊겨 있으면 선물 안내도 받지 못합니다.
  2. 설정 → 구독·구독권 선물 감사 인사가 켜져 있는지, 선물 인사 문구가 비어 있지 않은지 확인합니다. 비어 있으면 기본 문구로 나갑니다.
  3. 그래도 안 되면 선물이 들어온 시각과 함께 문의해 주세요. 치지직이 안내 문구를 바꾸면 아인이 알아보지 못할 수 있어서, 확인 뒤 업데이트로 고칩니다.

설정을 바꿨는데 반영이 안 돼요

증상: 문구나 명령어를 바꿨는데 봇은 예전 그대로 대답합니다.

확인
  1. 설정 화면 아래의 [저장]을 눌렀는지 확인합니다. 저장하면 봇이 켜진 상태에서도 몇 초 안에 반영됩니다.
  2. API 키나 봇 계정(부계정) 정보를 바꾼 경우에만 봇을 껐다 켜야 합니다.
  3. 그래도 안 되면 앱이 1.7 이전 버전일 수 있습니다. Microsoft Store에서 업데이트하세요. 현재 버전은 업데이트 기록에서 확인할 수 있습니다.

초기 설정 화면이 다시 열려요

증상: 잘 쓰던 아인을 켰는데 처음 설치할 때 봤던 "초기 설정" 화면이 다시 나옵니다.

치지직 로그인 정보가 지워질 때 나오는 정상 동작입니다. API 키를 바꿨거나, 치지직 쪽에서 로그인이 만료·거부(401/403)된 경우 아인이 로그인 정보를 지우고 다시 로그인을 안내합니다.

해결
  1. 안내대로 방송 계정으로 다시 로그인만 하면 됩니다. API 키를 다시 발급받을 필요는 없습니다.
  2. 출석 기록, 명령어, 문구 설정은 그대로 남아 있습니다.

로그인하다가 하얀 화면에서 멈춰요

증상: 네이버 로그인과 2단계 인증까지는 되는데, 마지막 치지직 연동 단계에서 하얀 화면만 나오고 끝나지 않습니다.

API 키(Client ID 또는 Client Secret)가 잘못 입력된 경우입니다. 키가 틀려도 네이버 로그인까지는 정상으로 진행되고, 치지직이 앱을 확인하는 마지막 단계에서 멈춥니다.

해결
  1. 로그인 창을 닫고 설정 → API 설정에서 개발자 센터의 Client ID와 Client Secret을 다시 복사해 붙여 넣습니다. 앞뒤 공백이 들어가지 않게 주의하세요.
  2. 개발자 센터에서 앱의 로그인 리다이렉트 URI가 설치 가이드의 값과 같은지 확인합니다. 설치 가이드 3단계 참고.
  3. 저장 후 다시 로그인합니다.

인사가 두 번 나가요

증상: 시청자가 인사하면 출석 인사가 두 개 올라오거나, 후원 인사가 겹칩니다.

  • 다른 채팅봇과 함께 쓰는 경우. 두 봇이 각자 인사합니다. 한쪽에서 해당 기능을 끄세요. 다른 봇의 출석 기록을 아인으로 옮기는 방법은 출석 가이드에 있습니다.
  • 아인이 두 개 켜진 경우. 아인은 한 번에 하나만 실행되도록 되어 있어 보통 생기지 않지만, 예전 방식(압축 파일)으로 설치한 것이 남아 있으면 둘 다 돌 수 있습니다. 예전 설치본 정리를 참고하세요.

무료 체험이 끝났다고 나와요

증상: 아인 창에 체험이나 이용권이 끝났다는 안내가 나오고 봇이 켜지지 않습니다.

해결
  1. 스마트스토어에서 이용권을 결제합니다. 1개월 2,900원부터입니다.
  2. 아인 설정 → [이용권]에 주문번호(또는 받은 연장 코드)를 붙여 넣습니다. 즉시 기간이 늘어나고, 기다릴 것은 없습니다.
  3. 봇을 시작합니다. 출석 기록과 설정은 체험이 끝나도 지워지지 않으므로 그대로 이어집니다.

주문번호를 넣었는데 "확인할 수 없다"고 나오면 결제가 완료된 주문인지 확인하고, 그래도 안 되면 주문번호와 함께 문의해 주세요.

창을 닫아도 봇이 계속 돌아요

증상: 아인 창의 X를 눌렀는데 봇이 계속 채팅에 응답하고, 작업 표시줄에서도 사라졌습니다.

의도된 동작입니다. 창을 닫으면 아인은 작업 표시줄 오른쪽 트레이로 숨고 봇은 계속 실행됩니다. 방송 중에 창을 실수로 닫아도 봇이 멈추지 않게 하기 위해서입니다.

봇을 완전히 끄려면
  1. 아인 창에서 [봇 중지]를 누르거나,
  2. 트레이의 아인 아이콘을 눌러 [앱 종료]를 선택합니다. 봇도 함께 멈춥니다.

Microsoft Store에서 설치가 안 돼요

증상: 설치 버튼이 반응하지 않거나, Store 앱이 열리지 않습니다.

  • 아인은 Windows 10 이상에서 동작합니다. Windows 업데이트가 오래 밀려 있으면 Store 자체가 안 열릴 수 있으니 업데이트 후 다시 시도하세요.
  • 회사·학교 PC처럼 Store 사용이 막힌 환경이라면 einbot.help@gmail.com 으로 문의해 주세요. 다른 설치 방법을 안내합니다.

그래도 안 되면

einbot.help@gmail.com 으로 보내 주세요. 평일 24시간 내에 답변합니다.

메일에 다음을 적어 주시면 빨리 찾을 수 있습니다.
