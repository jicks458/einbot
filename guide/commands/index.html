출석 체크

!출첵 대신 "안녕하세요"만 입력해도 출석으로 기록됩니다. 출석의 하루는 새벽 5시를 기준으로 바뀝니다. 문구와 기준을 변경하는 방법은 출석 가이드에서 확인할 수 있습니다.

방장·매니저 전용 명령어

방장과 채널·채팅 매니저만 사용할 수 있습니다. 시청자가 입력하면 봇이 응답하지 않습니다. 이 명령어들의 이름은 변경할 수 없습니다.

내가 만든 명령어

▶ 영상으로 보기 (1분 34초)

명령어를 만드는 방법은 두 가지이며, 어느 방법을 써도 결과는 같습니다.

방법 1. 방송 중 채팅에서 바로

초코우유 !명령어추가 유튜브 다시보기는 유튜브에 올라와요

초코우유 봇 ✅ !유튜브 명령어를 추가했어요.

별빛여우 !유튜브

초코우유 봇 다시보기는 유튜브에 올라와요

방법 2. 설정 창에서

설정 → 내가 만든 명령어에서 [+ 명령어 추가]를 누르고, 이름과 대답을 입력한 뒤 [저장]을 누릅니다. 목록은 한 줄씩 접혀 있으며, 줄을 누르면 펼쳐져 수정할 수 있습니다.

대답에는 {이름} {호칭} {횟수}(이 명령어가 사용된 횟수)를 넣을 수 있습니다. 이름은 기본 명령어나 관리 명령어와 같을 수 없으며, 대답은 !로 시작할 수 없습니다. 같은 이름으로 다시 추가하면 기존 대답이 새 대답으로 바뀝니다.

문구와 이름 바꾸기

아인 창의 [설정]을 누르면 설정 창이 열립니다. 왼쪽 목록에서 변경할 항목을 선택하고 [저장]을 누르면 봇을 다시 시작하지 않아도 바로 적용됩니다. 연결 방식, 방송 계정, 봇 계정을 변경한 경우에만 봇을 다시 시작해야 합니다.

  • "시청자를 부르는 방식": 기본값은 {이름} 치수입니다. {이름} 님과 같이 변경할 수 있습니다.
  • "명령어 앞 기호": 기본값은 !입니다. 다른 봇과 겹치면 ?나 #으로 변경합니다.
  • "전체 대기시간"·"1인 대기시간": 같은 명령어를 다시 사용할 수 있을 때까지의 대기시간(초)입니다. 기본값은 5초와 15초이며, 방장과 매니저에게는 적용되지 않습니다.
  • 설정 → 기본 명령어: 명령어별로 끄거나 이름과 대답을 변경합니다. 줄 앞의 체크 칸으로 켜고 끌 수 있으며, 이름을 누르면 줄이 펼쳐집니다. 이름은 쉼표로 구분해 여러 개를 등록할 수 있습니다. 예: 업타임, 방송시간

출석 설정은 출석 가이드, 후원·구독·팔로우 인사는 인사 가이드, 자동 시작 끄기는 문제 해결에서 확인할 수 있습니다.

반복 공지

방송 중에 설정한 간격마다 공지를 전송합니다.

  1. 설정 → 반복 공지에서 [+ 공지 추가]를 누릅니다.
  2. 전송 간격(분)과 내용을 입력하고 [저장]을 누릅니다. 공지 목록은 한 줄씩 접혀 표시되며, 줄을 누르면 펼쳐집니다.

간격은 방송을 시작한 시점부터 계산합니다. 공지를 여러 개 등록하면 각 공지가 설정한 간격에 따라 전송됩니다.

디스코드 알림

방송이 시작되면 디스코드 채널에 알림 메시지를 1회 전송합니다. 알림을 받을 채널의 웹훅 주소를 입력하고 "디스코드 알림 사용"을 켜면 됩니다. 이 기능은 기본으로 꺼져 있습니다.

웹훅 주소 만들기 (디스코드에서)

  1. 디스코드 서버 설정 → 연동 → 웹후크에서 [새 웹후크]를 누릅니다.
  2. "채널"에서 알림을 받을 채널을 선택합니다.
  3. [웹후크 URL 복사]를 누릅니다.

아인에서

  1. 설정 → 디스코드 알림에 웹훅 주소를 붙여 넣습니다.
  2. [테스트 보내기]를 눌러 디스코드에 메시지가 도착하는지 확인합니다. 문구에 @everyone이 있으면 테스트 메시지도 서버의 모든 멤버에게 알림이 전송됩니다.
  3. "디스코드 알림 사용"을 켜고 [저장]을 누릅니다. 이 항목을 끈 상태로 저장하면 알림이 전송되지 않습니다.

[테스트 보내기]가 실패하면 버튼 옆에 실패 원인과 조치 방법이 표시됩니다(버전 2.8.0부터).

표시되는 문구조치 방법
웹훅 주소가 틀리거나 지워졌습니다 (404 등)디스코드에서 웹훅 주소를 다시 복사해 입력합니다. 웹훅을 삭제했다면 새로 만듭니다.
디스코드가 글을 받지 않았습니다 (400)문구를 수정해 다시 보냅니다. 포럼 채널의 웹훅이라면 다른 채널의 웹훅을 입력합니다.
디스코드가 너무 잦다고 막았습니다 (429)잠시 후 다시 보냅니다.
디스코드에 보내지 못했습니다 (번호)잠시 후 다시 보냅니다.
디스코드에 닿지 못했습니다인터넷 연결을 확인하고 다시 보냅니다.

알림은 방송마다 한 번만 전송됩니다. 방송 시작 후 10분이 지난 뒤 봇을 켜면 알림을 전송하지 않습니다. 마지막 알림을 전송한 뒤 30분 이내에 방송을 다시 시작한 경우에도 전송하지 않습니다. 방송 종료 알림은 전송하지 않습니다.

알림을 보내지 못해 아인 창에 노란색 안내 띠가 표시되면, 웹훅을 다시 만들어 새 주소를 입력합니다. 웹훅 주소는 내 컴퓨터에만 저장됩니다. 디스코드로 전송되는 내용은 개인정보처리방침에서 확인할 수 있습니다.

자주 묻는 것

시청자가 명령어를 입력했는데 봇이 대답하지 않아요

같은 명령어를 채널 전체에서 5초 이내, 같은 시청자가 15초 이내에 다시 입력하면 봇이 응답하지 않습니다. 명령어 앞 기호가 설정과 다른 경우, 봇이 꺼져 있는 경우, 방송 중이 아닌 경우에도 응답하지 않습니다. 방장과 매니저에게는 대기시간이 적용되지 않습니다.

시청자도 명령어를 추가할 수 있나요?

아니요. !명령어추가, !명령어삭제, !출석보정은 방장과 채널·채팅 매니저만 사용할 수 있습니다. 시청자가 입력하면 봇이 응답하지 않습니다.

다른 봇과 같이 써도 되나요?

네, 함께 사용할 수 있습니다. 두 봇에 같은 이름의 명령어가 있으면 두 봇이 모두 응답합니다. 이 경우 아인의 명령어 앞 기호를 변경하거나 겹치는 명령어를 끄시기 바랍니다.
