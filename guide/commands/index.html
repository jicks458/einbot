설치 직후부터 바로 됩니다. 이름과 대답은 설정 화면에서 바꿀 수 있고, 안 쓰는 건 끌 수 있습니다.

"치수"는 기본 호칭입니다. 시청자를 부르는 방식은 설정에서 "{이름} 님"처럼 바꿀 수 있습니다.

출석 체크는 조금 특별합니다

  • 명령어 없이 인사만 해도 출석됩니다. 시청자가 "안녕하세요"라고만 쳐도 출석 처리됩니다. 어떤 인사말을 출석으로 볼지는 설정에서 정합니다.
  • 하루의 기준은 새벽 5시입니다. 자정이 아니라 새벽 5시에 날이 바뀌므로, 밤샘 방송 중에 출석이 두 번 잡히지 않습니다. 이 시각도 바꿀 수 있습니다.
  • 상황에 따라 다른 인사를 합니다. 처음 온 시청자, 8일 넘게 안 오다 온 시청자, 오늘 이미 출석한 시청자에게 각각 다른 문구가 나갑니다. 문구는 전부 바꿀 수 있습니다.
  • 출석에는 대기시간이 없습니다. 여러 시청자가 동시에 인사해도 모두 받아줍니다.

출석 문구와 기준을 바꾸는 방법은 출석 체크 봇 설정 방법에 따로 정리했습니다.

초코우유 봇 달빛토끼 치수, 안녕하세요~ 🎉 첫 출석이에요! 와주셔서 반가워요, 앞으로 자주 봬요!

초코우유 봇 별빛여우 치수, 오늘은 이미 출석했어요! 다음 출석은 7시간 28분 후에 가능해요.

방장·매니저 전용 명령어

방장(스트리머)과 채널 매니저, 채팅 매니저만 쓸 수 있습니다. 시청자가 치면 아무 반응이 없습니다. 이름은 고정이라 바꿀 수 없습니다.

명령어하는 일

!명령어삭제 이름내가 만든 명령어를 지웁니다.

내가 만든 명령어

만드는 방법은 두 가지이고 결과는 같습니다.

방법 1. 방송 중 채팅에서 바로

초코우유 !명령어추가 유튜브 다시보기는 youtube.com/@chocomilk 에 올라와요

초코우유 봇 ✅ !유튜브 명령어를 추가했어요.

별빛여우 !유튜브

초코우유 봇 다시보기는 youtube.com/@chocomilk 에 올라와요

방법 2. 설정 화면에서

아인 창의 [설정] → 내가 만든 명령어 → [+ 명령어 추가]에서 이름과 대답을 적고 저장합니다. 여러 개를 한 번에 정리할 때 편합니다.

대답에 넣을 수 있는 치환자

  • {이름} 명령어를 친 시청자의 닉네임
  • {호칭} 설정한 호칭을 붙인 이름. 예: 별빛여우 치수
  • {횟수} 이 명령어가 지금까지 쓰인 횟수. 예: !명령어추가 물 {호칭} 덕분에 {횟수}번째 물 마셨어요 💧

규칙

  • 이름은 기본 명령어, 관리 명령어와 겹칠 수 없습니다.
  • 대답은 !로 시작할 수 없습니다. 봇이 자기 명령어를 부르는 무한 반복을 막기 위해서입니다.
  • 같은 이름으로 다시 추가하면 대답이 새 내용으로 바뀝니다.
  • 추가한 명령어는 !명령어 목록에 자동으로 들어갑니다.

자주 만드는 것들: !디스코드 !유튜브 !일정 !컨텐츠 !사양 !후원. 시청자가 매번 묻는 질문이 있다면 그게 명령어 후보입니다.

문구와 이름 바꾸기

아인 창의 [설정]을 누르면 브라우저에 설정 화면이 열립니다. 명령어 설정 항목에서 아래를 바꿀 수 있고, 저장하면 봇이 켜진 상태에서도 바로 반영됩니다. API 키나 봇 계정을 바꿨을 때만 봇을 껐다 켜면 됩니다.

  • 시청자를 부르는 방식: 기본은 "{이름} 치수". "{이름} 님", "{이름}아" 처럼 방송 분위기에 맞게.
  • 명령어 앞 기호: 기본은 !. 다른 봇과 겹치면 ?나 #으로.
  • 대기시간: 같은 명령어를 채널 전체가 다시 쓸 수 있을 때까지 5초, 한 사람이 다시 쓸 수 있을 때까지 15초가 기본입니다. 도배를 막는 장치이고, 방장과 매니저는 적용받지 않습니다.
  • 출석 체크: 명령어 이름, 출석으로 볼 인사말, 하루가 바뀌는 시각, "오랜만" 기준 일수, 상황별 4가지 문구.
  • 명령어: 기본 명령어마다 끄기, 이름 바꾸기, 대답 바꾸기. 이름은 쉼표로 여러 개를 둘 수 있어서 !업타임과 !방송시간이 같은 일을 하게 할 수 있습니다.
  • 후원 감사 인사, 구독·구독권 선물 감사 인사: 켜고 끄기와 문구. 자세한 건 후원·구독 감사 인사 가이드에서 다룹니다.

반복 공지

봇이 켜져 있는 동안 정한 간격으로 자동 전송합니다. 설정 화면의 반복 공지에서 [+ 공지 추가] 후 간격(분)과 내용을 적습니다. 예를 들어 20분마다 "구독하면 이모티콘이 열려요 💚" 같은 안내를 내보낼 수 있습니다. 여러 개를 두면 각자 간격대로 나갑니다. 필요 없으면 비워 두면 됩니다.

자주 묻는 것

시청자가 명령어를 쳤는데 봇이 대답하지 않아요

대기시간 안에 다시 친 경우가 가장 흔합니다. 그 밖에 명령어 앞 기호가 설정과 다르거나, 봇이 꺼져 있거나, 방송 중이 아닐 때입니다. 방장과 매니저는 대기시간이 없어서 직접 테스트하면 항상 대답합니다.

시청자도 명령어를 추가할 수 있나요?

아니요. 추가·삭제·출석 보정은 방장과 매니저만 됩니다. 시청자가 치면 아무 반응이 없습니다.

다른 봇과 같이 써도 되나요?

됩니다. 다만 두 봇에 같은 이름의 명령어가 있으면 둘 다 대답합니다. 아인의 명령어 앞 기호를 바꾸거나 겹치는 명령어를 끄세요.

설정을 바꿨는데 반영이 안 돼요

설정 화면에서 [저장]을 눌렀는지 확인하세요. 저장하면 봇이 켜진 상태에서도 몇 초 안에 반영됩니다. 그래도 안 되면 앱이 1.7 이전 버전일 수 있으니 Microsoft Store에서 업데이트하세요. API 키나 봇 계정을 바꾼 경우에만 봇을 껐다 켜야 합니다.
