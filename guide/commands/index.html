출석 체크

!출첵 말고 "안녕하세요"만 쳐도 출석됩니다. 하루는 새벽 5시에 바뀝니다. 문구와 기준을 바꾸는 법은 출석 가이드에 있습니다.

방장·매니저 전용 명령어

방장과 채널·채팅 매니저만 쓸 수 있습니다. 시청자가 치면 아무 반응이 없고, 이름은 바꿀 수 없습니다.

명령어하는 일
!명령어추가 이름 내용새 명령어를 만듭니다. 예: !명령어추가 디스코드 주소는 discord.gg/xxxx 예요!
!명령어삭제 이름내가 만든 명령어를 지웁니다.

내가 만든 명령어

만드는 방법은 두 가지이고 결과는 같습니다.

방법 1. 방송 중 채팅에서 바로

초코우유 !명령어추가 유튜브 다시보기는 youtube.com/@chocomilk 에 올라와요

초코우유 봇 ✅ !유튜브 명령어를 추가했어요.

별빛여우 !유튜브

초코우유 봇 다시보기는 youtube.com/@chocomilk 에 올라와요

방법 2. 설정 창에서

설정 → 내가 만든 명령어에서 [+ 명령어 추가]를 누르고, 이름과 대답을 적은 뒤 [저장]합니다.

대답에는 {이름} {호칭} {횟수}(이 명령어가 쓰인 횟수)를 넣을 수 있습니다. 이름은 기본·관리 명령어와 겹칠 수 없고, 대답은 !로 시작할 수 없습니다. 같은 이름으로 다시 추가하면 대답이 바뀝니다.

문구와 이름 바꾸기

아인 창의 [설정]을 누르면 설정 창이 열립니다. 왼쪽 목록에서 고칠 것을 고르고 [저장]하면 봇이 켜진 채로 바로 반영됩니다. API 키·방송 계정·봇 계정을 바꿨을 때만 봇을 껐다 켭니다.

  • "시청자를 부르는 방식": 기본은 {이름} 치수입니다. {이름} 님처럼 바꿉니다.
  • "명령어 앞 기호": 기본은 !입니다. 다른 봇과 겹치면 ?나 #으로 바꿉니다.
  • "전체 대기시간"·"1인 대기시간": 같은 명령어를 다시 쓰기까지 기다리는 초입니다. 기본은 5초와 15초이고, 방장과 매니저는 기다리지 않습니다.
  • 설정 → 기본 명령어: 명령어마다 끄거나 이름·대답을 바꿉니다. 이름은 쉼표로 여러 개를 둘 수 있습니다. 예: 업타임, 방송시간

출석은 출석 가이드, 후원·구독·팔로우 인사는 인사 가이드, 자동 시작 끄기는 문제 해결에 있습니다.

반복 공지

방송 중에 정한 간격마다 공지를 보냅니다.

  1. 설정 → 반복 공지에서 [+ 공지 추가]를 누릅니다.
  2. 몇 분마다 보낼지와 내용을 적고 [저장]합니다.

방송을 켠 순간부터 간격을 셉니다. 여러 개를 두면 각자 간격대로 나갑니다.

디스코드 알림

방송이 시작되면 디스코드 채널에 메시지를 하나 보냅니다. 채널의 웹훅 주소만 있으면 됩니다. 처음에는 꺼져 있습니다.

웹훅 주소 만들기 (디스코드에서)

  1. 디스코드 서버 설정 → 연동 → 웹훅에서 [새 웹훅]을 누릅니다.
  2. "채널"에서 알림을 올릴 채널을 고릅니다.
  3. [웹훅 URL 복사]를 누릅니다.

아인에서

  1. 설정 → 디스코드 알림에 웹훅 주소를 붙여 넣습니다.
  2. [테스트 보내기]를 눌러 디스코드에 메시지가 오는지 봅니다.
  3. "방송 시작을 디스코드에 알림"을 켜고 [저장]합니다.

같은 방송은 한 번만 알립니다. 봇을 방송 시작 10분 뒤에 켜면 알리지 않습니다. 마지막 알림을 보낸 지 30분 안에 방송을 다시 켜도 알리지 않습니다. 방송 종료는 알리지 않습니다.

보내지 못해 아인 창에 노란 띠가 뜨면, 웹훅을 다시 만들어 주소를 새로 넣습니다. 웹훅 주소는 내 컴퓨터에만 저장되고, 디스코드로 보내는 내용은 개인정보처리방침에 있습니다.

자주 묻는 것

시청자가 명령어를 쳤는데 봇이 대답하지 않아요

같은 명령어를 채널 전체가 5초, 한 사람이 15초 안에 다시 치면 대답하지 않습니다. 명령어 앞 기호가 설정과 다르거나, 봇이 꺼져 있거나, 방송 중이 아니어도 대답하지 않습니다. 방장과 매니저는 대기시간이 없습니다.

시청자도 명령어를 추가할 수 있나요?

아니요. !명령어추가, !명령어삭제, !출석보정은 방장과 채널·채팅 매니저만 쓸 수 있습니다. 시청자가 치면 아무 반응이 없습니다.

다른 봇과 같이 써도 되나요?

됩니다. 두 봇에 같은 이름의 명령어가 있으면 둘 다 대답합니다. 아인의 명령어 앞 기호를 바꾸거나 겹치는 명령어를 끄면 됩니다.
