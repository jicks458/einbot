기능 창 여는 법

아인 창에서 봇을 켠 다음 [⚙ 설정] 아래의 [✦ 기능] 버튼을 누르세요. 투표와 추첨이 채팅을 읽어야 하기 때문에 봇이 꺼져 있으면 열리지 않습니다. 창 왼쪽 목록에서 투표·추첨·돌림판·후원 룰렛(참여 기능)과 카운터·타이머·스톱워치(시간 기능)를 고릅니다.

이 창은 봇이 켜져 있는 동안 내 컴퓨터 안에서만 동작합니다. 다른 사이트에 접속하거나 별도로 가입할 것이 없습니다.

투표

질문과 보기(최대 9개)를 적고 시간을 고른 뒤 [투표 시작]을 누릅니다. 시청자는 채팅에 번호만 치면 됩니다. "2", "2번", "!투표 2" 모두 됩니다.

초코우유 봇 📊 투표 시작! 채팅에 번호만 쳐 주세요 — 오늘 뭐 할까? (1. 게임 / 2. 잡담)

별빛여우 1

달빛토끼 2번

… 90초 뒤

초코우유 봇 📊 오늘 뭐 할까? — 1. 게임 12표(60%) · 2. 잡담 8표(40%) · 총 20표

  • 한 사람 한 표. 나중에 친 번호가 앞의 표를 덮어씁니다.
  • 표마다 봇이 대답하지 않습니다. 채팅이 도배되지 않게 하려는 것이고, 집계는 기능 창과 오버레이에서 실시간으로 보입니다.
  • 결과 가리기를 켜면 종료 때까지 시청자 화면(오버레이)에는 표 수가 "?"로 나옵니다. 방장 창에서는 계속 보입니다.
  • "직접 종료"를 고르면 [종료]를 누를 때까지 받습니다. 시작·결과 채팅은 끌 수 있고 문구는 바꿀 수 있습니다.

추첨

[모집 시작]을 누르면 그때부터 채팅한 사람이 자동으로 참여자에 들어갑니다. 특정 말을 쳐야 들어오게 하려면 키워드를 적으세요(예: 참여). [모집 마감] 뒤 인원을 정해 [뽑기]를 누르면 무작위로 뽑고 채팅에 알립니다.

  • 같은 사람은 한 번만 들어갑니다. 이미 당첨된 사람은 다시 뽑지 않으니, 당첨자가 없으면 [뽑기]를 한 번 더 누르면 됩니다.
  • 참여자 이름은 기능 창 오른쪽과 방송 화면 양쪽에 나옵니다. 화면에 명단을 안 보이게 하려면 모집 카드의 "방송 화면에 참여자 명단 표시"를 끄세요.
  • [모집 마감] 뒤 [모집 재개]를 누르면 참여자를 지우지 않고 다시 받습니다. 처음부터 하려면 [초기화].
  • 구독자만 받는 기능은 아직 없습니다. 채팅 정보에 구독 여부가 실려 오는지 확인한 뒤 넣을 예정입니다.

돌림판

방장이 직접 돌리는 룰렛입니다. 항목과 확률을 적어 저장하고 [돌리기]를 누르면 기능 창의 원판과 방송 화면의 원판이 같이 돌아갑니다.

  • 확률 합이 100이 아니어도 비율대로 돕니다. 항목마다 색은 자동으로 붙습니다.
  • 돌림판은 여러 개 만들 수 있습니다(벌칙판, 선물판…). 회전 시간은 2~30초.
  • 결과를 채팅에 올릴지, 문구를 어떻게 할지 정할 수 있습니다. 기본 문구는 🎰 {대상} → {결과}!
  • 결과는 날짜와 함께 기록에 남아 나중에 볼 수 있습니다.

후원 룰렛

정해 둔 금액이 후원되면 방송 화면에서 룰렛이 자동으로 돌고, 다 돌면 결과가 채팅에 올라갑니다. 규칙은 여러 개 둘 수 있습니다.

항목뜻
금액정확히 이 금액일 때만 돕니다. 1,000원 룰렛에 1,500원을 후원하면 돌지 않습니다.
감지 키워드적어 두면 후원 메시지에 그 말이 있을 때만 돕니다. 같은 금액으로 다른 룰렛을 나눌 때 씁니다.
돌림판어느 돌림판을 돌릴지.
연차켜면 2배·3배 금액에 2번·3번 돕니다. "한 번에 N회까지" 상한을 넘지 않습니다.
하루 최대하루에 도는 횟수 제한. 0이면 제한 없음.

시스템 익명의 후원자 님이 1,000원을 후원하셨습니다

초코우유 봇 🧡 익명의 후원자, 1000원 후원 감사합니다!

… 방송 화면의 룰렛이 6초 돌고

초코우유 봇 🧀 익명의 후원자 1000원 → 노래 한 곡!

  • 오버레이를 OBS에 안 넣어 두어도 채팅 결과는 나갑니다. 화면에 원판을 보여 주고 싶을 때만 오버레이를 넣으면 됩니다.
  • 익명 후원도 돕니다. 이름 자리에 "익명의 후원자"가 들어갑니다.
  • 후원 인사와 별개입니다. 후원 인사는 후원·구독 감사 인사에서 따로 켜고 끕니다.
  • 실제 후원 없이 확인하려면 [첫 규칙 테스트]를 누르세요.

OBS에 띄우기

각 화면 아래에 OBS 브라우저 소스 URL과 권장 크기가 있습니다. [URL 복사] → OBS에서 소스 추가 → 브라우저 → URL에 붙여넣고, 폭·높이를 권장 크기(예: 투표 560×420, 추첨 900×420)로 두면 1920×1080 화면에 딱 맞고 또렷합니다. 배경은 투명입니다.

오버레이주소보이는 것
투표http://localhost:8391/overlay/vote질문, 남은 시간, 보기별 막대. 1위 왼쪽에 초록 선, 끝나면 세 번 깜빡임
추첨http://localhost:8391/overlay/raffle참여 인원, 참여자 명단(끌 수 있음), 뽑을 때 초록 테두리가 닉네임 사이를 돌다가 당첨자에 멈춤
돌림판http://localhost:8391/overlay/wheel돌 때만 나타나 8초 뒤 사라짐. 항상 보이게: ?hidden=0, 크기: ?size=400
후원 룰렛http://localhost:8391/overlay/roulette후원이 오면 자동으로 돌고 결과 표시

글자 크기·색·배경은 기능 창의 오버레이 꾸미기에서 한 번에 바꿉니다. 포트 8391이 다른 프로그램과 겹치면 아인이 8392~8395 중 빈 곳을 쓰고, 기능 창의 주소가 그에 맞게 바뀝니다.

자주 묻는 것

[기능] 버튼을 눌렀는데 "봇을 먼저 켜 주세요"라고 나와요.

투표·추첨은 채팅을 읽어야 해서 봇이 켜져 있어야 합니다. 봇을 켜고 몇 초 뒤 다시 누르세요.

OBS에 아무것도 안 보여요.

봇이 켜져 있는지, 주소를 정확히 붙였는지 확인하세요. 돌림판 오버레이는 돌 때만 나타나는 것이 기본입니다. 브라우저 소스의 "소스가 보이지 않을 때 종료" 옵션은 꺼 두세요.

시청자가 명령어를 쳐야 하나요?

아니요. 투표는 번호, 추첨은 채팅 한 줄(또는 정한 키워드)이면 됩니다. 방장 쪽도 창의 버튼뿐이라 명령어를 외울 것이 없습니다.
