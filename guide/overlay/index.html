먼저 알아 둘 것

▶ 영상으로 보기 (1분 32초)

기능 창은 봇이 실행 중일 때만 열립니다. 봇을 끄면 채팅 오버레이와 TTS도 함께 중지됩니다.

OBS에 추가하는 방법은 모든 화면이 같습니다.

  1. 기능 창 각 화면의 [URL 복사]를 누릅니다.
  2. OBS에서 소스 추가 → 브라우저를 선택하고 URL 칸에 붙여 넣습니다.
  3. 폭과 높이를 화면에 안내된 권장 크기로 설정합니다. 배경은 투명합니다.

주소와 포트는 업데이트 후에도 바뀌지 않습니다. 신청곡·TTS·TITS, 알림 오버레이의 팔로우 카드와 알림 소리는 기본으로 꺼져 있습니다.

아인을 아직 설치하지 않았다면 → 설치 가이드(5분)

채팅 오버레이

▶ 영상으로 보기 (1분 19초)

방송 화면에 채팅을 표시합니다. 기본 디자인은 흰색 둥근 상자에 검은색 글자이며, 닉네임 색과 배지는 치지직 채팅창과 같게 표시됩니다.

  1. 기능 창 → 채팅 오버레이에서 프리셋을 선택합니다. 변경한 값은 바로 적용됩니다.
  2. [URL 복사]를 눌러 OBS에 추가합니다. 권장 크기는 480 × 720입니다.
항목하는 일
프리셋흰 박스(기본)·어둡게·투명·네온·파스텔 중 선택합니다. 선택하면 아래 값이 한 번에 바뀝니다.
닉네임"치지직 색 그대로", "사람마다 랜덤", "글자색과 같게", "한 색으로" 중 선택합니다.
지우기 · 줄 수채팅이 사라지기까지의 시간(초, 0이면 계속 표시)과 한 번에 표시할 줄 수(기본 12)를 정합니다.

화면마다 다르게 설정하려면 주소 뒤에 ?stay=8&max=6&bot=0과 같이 붙입니다. 각각 사라지기까지의 시간(초), 줄 수, 봇 답변 숨김을 뜻합니다.

공유되는 채팅 CSS 그대로 쓰기

트위치에서부터 널리 공유되어 온 채팅 CSS(KapChat 계열)와 뚜봇 "커스텀 치지직 채팅 오버레이"용 CSS는 구조가 같아 그대로 사용할 수 있습니다.

  1. 채팅 오버레이 화면의 "CSS 직접 넣기" 칸에 CSS를 붙여 넣습니다.
  2. [적용]을 누릅니다. 미리보기에 바로 표시되면 적용이 완료된 것입니다.

OBS 브라우저 소스의 "사용자 지정 CSS"에 넣어도 됩니다. [예시 CSS]를 누르면 아래 구조의 예시가 입력됩니다.

#log > div.chat_line.chzzk[.streamer|.manager|.bot]
  > span.meta (span.badges img.badge, span.name)
    span.colon
    span.message (span.emote_wrap img.emoticon.emote)

CSS를 넣으면 색과 상자 모양은 해당 CSS를 따릅니다. [비우기]를 누르면 "디자인"에서 설정한 모양으로 돌아갑니다. 치지직 채팅창 자체를 꾸미는 CSS는 구조가 달라 사용할 수 없습니다.

알림 오버레이

▶ 영상으로 보기 (1분 31초)

후원, 구독, 구독권 선물, 새 팔로우, 룰렛·투표 결과, 추첨 당첨, 타이머 종료를 방송 화면에 카드로 표시합니다.

  • 알림 종류별로 켜고 끌 수 있으며, 표시 시간(기본 6초)을 정한 뒤 [저장]을 누릅니다. 권장 크기는 560 × 200입니다.
  • 팔로우 카드는 기본으로 꺼져 있으며, 봇 계정이 채널 관리자로 지정되어 있어야 표시됩니다 → 준비 방법
  • [테스트]를 누르면 OBS에 카드가 표시되고, 켜 둔 알림 소리도 재생됩니다.
  • 후원 룰렛이 실행되는 후원은 후원 카드가 먼저 표시되고, 룰렛이 멈추면 결과 카드가 표시됩니다.

알림 소리

알림 소리는 기본으로 꺼져 있습니다.

  1. 같은 화면 오른쪽(창이 좁으면 아래)의 "알림 소리"를 선택합니다.
  2. "소리"에서 기본음 네 가지(종·차임·반짝·팝) 중 하나를 선택합니다.
  3. 직접 준비한 소리를 사용하려면 "내 파일"을 선택하고 [파일 고르기]로 파일을 등록합니다(mp3·wav·ogg·m4a, 최대 3MB).
  4. 음량과 "소리 낼 알림"을 설정하고 해당 칸의 [저장]을 누릅니다.

후원 알림 소리는 치지직 후원 알림과 겹치므로 기본으로 꺼져 있습니다. 알림 소리는 OBS에 추가한 알림 오버레이에서 재생되며, [들어 보기]는 기능 창에서만 들립니다. 소리가 들리지 않으면 → 알림 소리가 안 나요

방송 화면에 넣기

신청곡 화면의 "방송 화면에 넣기"에는 주소가 두 개 있습니다. 추가하는 방법은 먼저 알아 둘 것과 같습니다.

화면하는 일권장 크기
1 플레이어영상과 소리를 재생합니다. 플레이어가 있어야 신청곡이 재생됩니다.480 × 270
2 곡 제목 표시
선택		제목·신청자·다음 곡을 가로 띠로 표시합니다. 소리는 재생하지 않습니다.980 × 140
  • 소리는 OBS 데스크톱 오디오로 출력됩니다. 소스의 "OBS를 통해 오디오 제어"를 켰다면 오디오 믹서의 해당 소스로 출력됩니다. 볼륨은 기능 창의 볼륨 막대로 조절합니다.
  • 장면을 전환해도 계속 재생하려면 플레이어 소스의 "보이지 않을 때 소스 종료"를 끕니다.
  • 더 선명한 화질을 원하면 플레이어 소스를 1280 × 720으로 설정하고 장면에서 크기를 줄입니다(기능 창 [화질을 높이려면?] 참고).
  • OBS 없이 재생하려면 [플레이어 창 열기]를 누릅니다. 플레이어 창과 OBS를 함께 열면 나중에 연 쪽에서만 재생됩니다.
  • OBS [상호작용]으로 자막·화질·음량을 바꾸려면 "방송 화면에 넣기"의 "OBS 플레이어에 조작 막대 보이기"를 켭니다. 이 경우 곡이 시작될 때 몇 초 동안 조작 막대가 방송 화면에도 표시됩니다.

곡 제목 표시

배경은 오버레이 꾸미기 설정을 따릅니다. 주소 뒤에 ?next=0을 붙이면 다음 곡 칸이 표시되지 않습니다.

채팅 명령어

명령어하는 일
!신청곡 링크곡을 신청합니다. 유튜브·쇼츠 링크나 영상 ID(11자)를 입력합니다.
!신청곡취소내가 마지막으로 신청한 곡을 취소합니다. 재생 중인 곡은 취소되지 않습니다.

시청자는 곡을 건너뛸 수 없습니다. 명령어 앞 기호를 변경했다면 변경한 기호로 입력합니다.

기능 창에서 하는 일

  • 기본 제한은 1인당 3곡, 곡 길이 8분, 같은 곡 재신청 24시간입니다.
  • 기능 창에서 직접 추가한 곡에는 1인당 최대 곡 수와 같은 곡 제한이 적용되지 않습니다.
  • 봇을 다시 시작해도 대기열은 유지되며, [재생 시작]을 눌러야 재생됩니다.
  • "지금 재생" 배지가 "플레이어 없음"으로 표시되면 1번 플레이어가 OBS에 추가되어 있지 않은 것입니다.
  • 신청곡 설정의 "유튜브 자막"을 켜면 OBS 플레이어와 플레이어 창에 자막이 함께 표시됩니다. 선택한 언어(한국어·영어·일본어)의 자막이 있는 곡만 자막을 표시합니다. 자막이 없는 곡도 그대로 재생됩니다. 유튜브가 자동으로 만든 자막은 표시하지 않습니다. 이 기능을 꺼 두어도 유튜브 자막이 켜져 있는 브라우저에서는 자막이 표시될 수 있습니다.
  • 곡 제목 표시를 플레이어 아래쪽에 겹쳐 두면 자막이 가려집니다.
  • OBS [상호작용]이나 플레이어 창에서 유튜브 플레이어로 일시 정지하거나 음량을 변경하면 기능 창과 다른 플레이어에도 같이 적용됩니다.

TTS 읽어주기

구독·구독권 선물·채팅을 Windows 한국어 음성으로 읽어 줍니다. TTS는 기본으로 꺼져 있습니다. 기능 창 → TTS 읽어주기에서 "TTS 사용"을 켜면 다음 채팅부터 읽습니다. 소리는 OBS 데스크톱 오디오로 출력됩니다.

항목하는 일
읽을 것"구독 읽기", "구독권 선물 읽기", "채팅 읽기", "닉네임도 읽기"를 각각 켜고 끌 수 있습니다.
속도-5 ~ 5. 0이 기본 속도입니다.
금지어 · 제외 닉네임쉼표로 구분해 입력합니다. 금지어가 포함된 문장과 입력한 닉네임의 채팅은 읽지 않습니다.

값을 변경한 뒤 [저장]을 누르고, [테스트 읽기]로 소리를 확인합니다. 읽기가 많이 밀려 있으면 [읽기 중지]를 누릅니다. 봇 답변, 명령어, 후원 메시지는 읽지 않습니다.

TITS 던지기

▶ 영상으로 보기 (1분 16초)

TITS는 시청자가 버튜버 아바타에 물건을 던질 수 있게 하는 프로그램입니다. 아인은 치지직의 후원·구독·구독권 선물·채팅 정보를 TITS에 전달합니다.

준비물: VTube Studio(Steam, 무료)와 TITS(Steam, ₩21,500)를 같은 PC에 설치합니다.

연결 순서

  1. VTube Studio 설정에서 "Start API (allow plugins)"를 켭니다.
  2. TITS를 실행하고, VTube Studio에 표시된 플러그인 허용 창에서 [Allow]를 누릅니다.
  3. TITS 설정(오른쪽 아래 톱니바퀴)의 API 칸에서 "Enabled"를 ON으로 설정합니다. 기본 포트는 42069입니다.
  4. 아인 기능 창 → TITS 던지기에서 "TITS 연동 사용"을 켭니다. 배지가 "연결됨"으로 바뀌면 연결이 완료된 것입니다(최대 15초). "연결되지 않음. TITS를 켜고 TITS 설정에서 API를 켜세요"가 계속 표시되면 3번 단계를 다시 확인합니다.
  5. [아이템 새로고침]을 누릅니다. TITS에 등록한 아이템·트리거 목록이 표시되면 설정이 완료된 것입니다.

규칙

[+ 규칙 추가]로 규칙을 만들고 조건을 선택하면, 해당 조건에 필요한 칸만 표시됩니다. 설정을 마치면 [저장]을 누릅니다.

조건쓰는 칸던지는 때
후원최소·최대 금액, 키워드, 개수, 비례금액이 범위 안에 있고 메시지에 키워드가 있을 때. 최대 금액을 비워 두면 제한이 없습니다(빈칸에 흐린 글자로 "없음" 표시).
구독개수 (티어 나누기를 켜면 2티어 따로)구독 메시지가 올라올 때.
구독권 선물개수, 비례 (티어 나누기를 켜면 2티어 따로)구독권 선물이 들어올 때.
채팅키워드, 개수채팅에 키워드가 있을 때. 같은 규칙은 10초에 한 번만 실행됩니다.
  • 비례를 켜면 후원은 최소 금액의 배수만큼, 구독권 선물은 선물한 장수만큼 개수를 곱합니다(최대 200개).
  • 아이템을 여러 개 선택하면(Ctrl+클릭) 그중 하나를 무작위로 던집니다. 트리거를 선택하면 아이템 대신 해당 트리거를 실행합니다.
  • 구독·구독권 선물은 모든 티어에 같은 설정으로 던집니다. 규칙의 "티어 나누기"를 켜면 아래에 2티어 줄이 추가되어 2티어일 때 던질 항목을 따로 설정할 수 있습니다. 처음 켜면 위 줄의 값이 2티어 줄로 복사되며, 끄면 다시 모든 티어에 위 줄의 설정이 적용됩니다. 설정해 둔 2티어 값은 다시 켜면 복원됩니다(버전 2.8.0부터).
  • 규칙을 선택하고 [테스트 던지기]를 누르면 후원 없이 시험할 수 있습니다. 티어 나누기를 켠 규칙은 목록에서 "이름 (2티어)"를 선택해 2티어 설정을 시험합니다.
  • TITS를 다시 실행하면 15초 이내에 자동으로 다시 연결됩니다.
