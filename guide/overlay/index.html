치지직 채팅 오버레이·신청곡·알림·TTS·TITS 설정 방법

아인 창의 [기능] 버튼을 누르면 열리는 기능 창에서 왼쪽 목록의 화면(채팅 오버레이·알림 오버레이)과 소리·연동(신청곡·TTS 읽어주기·TITS 던지기)을 다룹니다. 설정을 바꾸면 오른쪽 미리보기에 바로 보이고, 저장하면 OBS 화면에도 그대로 나옵니다.

먼저 알아 둘 것

  • 기능 창은 봇이 켜져 있을 때만 열립니다. 채팅 오버레이와 TTS는 채팅을 읽어야 하니 봇이 꺼지면 같이 멈춥니다.
  • 각 화면 아래에 OBS 브라우저 소스 URL과 권장 크기가 있습니다. [URL 복사] → OBS 소스 추가 → 브라우저 → URL 붙여넣기 → 폭·높이를 권장 크기로. 배경은 투명입니다.
  • URL과 포트는 한 번 정해지면 업데이트해도 바뀌지 않습니다.
  • 신청곡·TTS·TITS는 처음에는 꺼져 있습니다. 켜기 전에는 아무것도 하지 않습니다.

채팅 오버레이

방송 화면에 채팅을 띄웁니다. 기본은 흰 둥근 상자에 검은 글씨입니다. 닉네임 옆 아이콘은 치지직 채팅창이 주는 배지(방장 왕관, 관리자, 구독 배지 등)만 그리고, 아인이 따로 붙이는 표시는 없습니다. 닉네임 색과 꾸미기(치트키 색, 2티어 그라데이션·하이라이트)도 치지직 채팅창과 같은 규칙으로 나옵니다.

항목뜻
프리셋흰 박스(기본) · 어둡게 · 투명 · 네온 · 파스텔. 누르면 아래 값이 한 번에 바뀝니다.
글꼴 · 크기 · 굵기Pretendard와 시스템 글꼴, 구글 폰트 32종(나눔·고운·주아·도현·검은고딕 등). 크기 기본 20.
글자색 · 닉네임 색닉네임 색은 치지직(채팅창과 같게), 랜덤(사람마다 다른 색), 글자색(본문과 같게), 단색(정한 색) 중 하나.
배경색 · 투명도 · 테두리 · 둥글기 · 그림자상자 모양. 투명도 0이면 상자 없이 글자만.
정렬 · 방향 · 간격 · 여백왼쪽/오른쪽 정렬, 새 채팅이 아래로/위로, 줄 사이 간격(기본 10), 상자 안 여백(기본 6).
표시 시간 · 최대 줄몇 초 뒤 사라질지(0이면 계속), 한 번에 몇 줄까지(기본 12).
봇 답변 표시 · 이모티콘 · 배지 · 콜론아인의 답변을 보일지, 이모티콘을 그림으로, 배지를 보일지, 닉네임 뒤 콜론.
  • 미리보기는 처음에 예시 채팅을 보여 주다가 실제 채팅이 올라오면 그것만 보여 줍니다. 봇을 끄면 다시 예시로 돌아갑니다.
  • 주소 뒤에 값을 붙여 화면마다 다르게 할 수도 있습니다. ?stay=8&max=6&bot=0처럼 표시 시간(초)·최대 줄·봇 답변 숨김.
  • 권장 크기 480 × 720. 세로로 긴 화면 한쪽에 두면 알맞습니다.

공유되는 채팅 CSS 그대로 쓰기

트위치 시절부터 돌아다니는 채팅 CSS(KapChat 계열)와 뚜봇 "커스텀 치지직 채팅 오버레이"용 CSS는 HTML 구조가 같아서 그대로 붙여 넣으면 됩니다. 기능 창의 CSS 직접 넣기에 붙이고 [적용]을 누르거나, OBS 브라우저 소스의 "사용자 지정 CSS"에 넣어도 됩니다. [예시 CSS 넣기]를 누르면 구조를 볼 수 있는 예시가 들어갑니다.

#log > div.chat_line.chzzk[.streamer|.manager|.bot]
  > span.meta (span.badges img.badge, span.name)
    span.colon
    span.message (span.emote_wrap img.emoticon.emote)
  • CSS를 넣으면 아인의 기본 상자 디자인은 빠지고 흰 글씨만 남습니다. 색·상자는 넣은 CSS가 정합니다. 지우면 기본으로 돌아옵니다.
  • 치지직 채팅창 자체를 꾸미는 CSS(네이버의 난수 클래스 이름을 쓰는 것)는 구조가 달라 맞지 않습니다.

알림 오버레이

후원, 구독, 구독권 선물, 룰렛 결과, 투표 결과, 추첨 당첨, 타이머 종료가 있을 때 화면에 카드를 하나 띄웁니다. 흰 반투명 둥근 상자에 검은 글씨입니다.

  • 종류별로 끄고 켤 수 있고, 표시 시간(기본 6초)을 정합니다. 여러 개가 겹치면 차례로 나옵니다.
  • 구독·구독권 선물 카드는 1티어면 티어를 적지 않고 2티어부터 "2티어"라고 적습니다.
  • [시험] 버튼으로 종류를 골라 카드를 띄워 볼 수 있습니다.
  • 권장 크기 560 × 200.

신청곡

신청곡 화면의 방송 화면에 넣기에 주소가 두 개 있습니다. [URL 복사] → OBS 소스 추가 → 브라우저 → URL 붙여넣기 → 폭·높이를 권장 크기로.

  • 소리는 PC 기본 출력으로 나가 OBS의 데스크톱 오디오로 방송에 들어갑니다. 볼륨은 기능 창의 볼륨 막대로 맞춥니다.
  • 장면을 바꿔도 계속 재생하려면 플레이어 소스 속성의 "보이지 않을 때 소스 종료"를 끄세요.
  • OBS 없이 이 PC에서만 틀 때는 [플레이어 창 열기]를 누르면 플레이어가 창으로 뜹니다. OBS와 창을 같이 열어 두면 나중에 연 곳에서만 소리가 나서 두 번 겹쳐 나오지 않습니다.

곡 제목 표시

  • 강조색(진행 막대·다음 곡 글씨)은 곡 썸네일에서 뽑아 곡마다 바뀝니다. 제목이 길면 옆으로 흐르며 끝까지 보여 줍니다.
  • 배경(어둡게·밝게·없음)과 크기는 오버레이 꾸미기를 따릅니다. 이 띠만 다르게 하려면 주소 뒤에 ?배경=밝게처럼 붙입니다.
  • 다음 곡 칸을 빼려면 주소 뒤에 ?next=0을 붙이세요.

기능 창에서 하는 일

항목뜻
지금 재생제목·가수·신청자·길이. 오른쪽 위 배지가 플레이어 연결됨이면 OBS나 플레이어 창이 붙은 것이고, 플레이어 없음이면 1번 플레이어가 아직 어디에도 없습니다.
다음 곡 · 일시정지 · 볼륨지금 곡을 넘기거나 멈추고, 소리 크기(0~100)를 정합니다.
대기열곡마다 [맨 위로]와 ✕(빼기), 위의 [모두 비우기]. 아래 칸에 링크를 붙여 넣으면 직접 추가됩니다. 직접 추가한 곡은 한 사람 최대·같은 곡 금지를 받지 않습니다.
신청 받기끄면 새 신청만 막고, 대기열에 있는 곡은 그대로 재생합니다.
한 사람 최대한 사람이 대기열에 올려 둘 수 있는 곡 수(기본 3).
곡 길이이보다 긴 곡은 재생을 시작할 때 넘깁니다(기본 8분, 0 = 제한 없음). 라이브 영상도 넘깁니다.
같은 곡 금지재생한 곡을 이 시간 동안 다시 받지 않습니다(기본 24시간, 0 = 제한 없음).
채팅 응답 · 신청 응답신청 결과를 채팅에 답합니다. 문구에 {호칭} {제목} {가수} {순서}를 넣을 수 있습니다.
곡이 바뀔 때 채팅 알림 · 재생 알림새 곡이 시작될 때 채팅에 알립니다(처음에는 꺼짐). 문구에 {제목} {가수} {신청자}.

그 밖에 같은 사람은 5초에 한 번 신청할 수 있고, 대기열은 50곡까지이며, 이미 대기열에 있는 곡은 다시 받지 않습니다. 봇을 껐다 켜면 대기열은 남지만 저절로 틀지 않습니다. 기능 창의 [재생 시작]을 누르면 첫 곡부터 재생합니다.

신청이 안 될 때 봇이 하는 말

봇의 답이유
유튜브 링크나 영상 ID로 신청해 주세요.링크가 아니거나 유튜브 링크가 아닙니다.
없는 영상이거나 퍼가기가 막혀 있어 재생할 수 없습니다.삭제·비공개 영상이거나, 영상 주인이 다른 곳에서 재생(퍼가기)을 막아 두었습니다. 일부 공식 뮤직비디오가 여기에 걸립니다.
한 사람당 대기 3곡까지 신청할 수 있습니다.한 사람 최대에 걸렸습니다. 앞 곡이 재생되면 다시 신청할 수 있습니다.
이미 대기열에 있는 곡입니다. / 최근 24시간 안에 재생한 곡입니다.같은 곡 제한입니다.
지금은 신청곡을 받지 않습니다.[신청 받기]가 꺼져 있습니다.
⏭ 8분이 넘는 곡이라 넘겼습니다 / 라이브 영상이라 넘겼습니다곡 길이는 재생을 시작해야 알 수 있어서, 대기열에 들어간 뒤 재생할 때 넘깁니다.
⏭ 재생할 수 없는 영상이라 넘겼습니다신청은 받았지만 플레이어에서 재생이 막힌 영상입니다(나라·연령 제한, 영상 주인의 재생 제한 등). 다음 곡으로 넘어갑니다.
광고와 저작권. 신청곡은 유튜브 공식 플레이어로 틉니다. 영상에 따라 유튜브 광고가 나올 수 있고, 아인은 광고를 막지 않습니다. 유튜브 규정상 영상 화면 없이 소리만 트는 방식은 없습니다. 방송에서 음악을 트는 데 따른 저작권 책임은 방송하는 분께 있으니, 치지직의 음악 저작권 정책을 확인하고 사용하세요.

TTS 읽어주기

구독·구독권 선물·채팅을 Windows에 내장된 한국어 음성으로 읽습니다. 설치할 것이 없고, 소리는 PC 기본 출력으로 나가서 OBS의 데스크톱 오디오에 잡힙니다. 처음에는 꺼져 있습니다. [TTS 사용]을 켜면 다음 채팅부터 읽고, 끄면 바로 조용해집니다.

TITS 던지기

TITS(Twitch Integrated Throwing System)는 시청자가 버튜버 아바타에 물건을 던지게 하는 프로그램입니다. 원래 트위치·유튜브만 알아듣는데, 아인이 치지직의 후원·구독·구독권 선물·채팅을 TITS에 전달합니다.

준비물. VTube Studio(Steam, 무료)와 TITS(Steam, ₩21,500 · 유료). 둘 다 같은 PC에 설치합니다. 아인은 TITS의 공개 API(내 PC 안 포트 42069)로만 말하고 인터넷으로 나가지 않습니다.

연결 순서

  1. VTube Studio 설정에서 Start API (allow plugins)를 켭니다(포트 8001).
  2. TITS를 켭니다. VTube Studio에 플러그인 허용 창이 뜨면 Allow. TITS 왼쪽 목록의 VTube Studio 옆이 ✓가 되면 붙은 것입니다. 안 되면 TITS의 VTube Studio 설정에서 [Deauthenticate] 뒤 TITS를 껐다 켜 보세요.
  3. TITS의 Connections 화면 오른쪽 API를 Enabled ON으로 두고 포트가 42069인지 봅니다.
  4. 아인 기능 창 → TITS 던지기에서 [TITS 연동 사용]을 켜고 [저장]. 배지가 "연결됨"이 됩니다(최대 15초). "연결 안 됨"이 계속이면 3번을 다시 보세요.
  5. [아이템 새로고침]을 누르면 TITS에 넣어 둔 아이템·트리거 목록이 옵니다. 아이템이 없으면 TITS의 Object Manager에서 이미지를 넣어 두세요.

규칙

규칙마다 조건을 고르면 그 조건에 뜻 있는 칸만 보입니다.

조건쓰는 칸동작
후원최소·최대 금액, 키워드, 개수, 비례금액이 범위 안이고(최대 0 = 제한 없음) 키워드가 후원 메시지에 있으면 던집니다. 비례를 켜면 최소 금액의 배수만큼 개수를 곱합니다(상한 200).
구독개수 (+ 2티어 가지)구독 메시지가 올라올 때 던집니다.
구독권 선물개수, 비례 (+ 2티어 가지)선물이 오면 던집니다. 비례를 켜면 선물한 장수만큼 곱합니다.
채팅키워드, 개수채팅에 키워드가 있으면 던집니다. 같은 규칙은 10초에 한 번만.
  • 아이템은 여러 개 고를 수 있고(Ctrl+클릭) 던질 때마다 그중 하나가 무작위로 날아갑니다. 트리거를 고르면 아이템 대신 TITS의 그 트리거를 실행합니다.
  • 구독·구독권 선물 규칙 아래에는 └ 2티어 가지가 붙습니다. 가지 앞의 체크가 켜져 있으면(기본) 2티어 구독·선물은 가지에 정한 아이템·개수로 던지고, 끄면 2티어도 위 행과 똑같이 던집니다. 시험은 [테스트 던지기] 목록에서 "이름 (2티어)"를 고르면 됩니다.
  • 규칙을 고르고 [테스트 던지기]를 누르면 실제 후원 없이 던져 볼 수 있습니다.
  • TITS를 껐다 켜면 아인이 15초 안에 다시 붙습니다. 봇을 껐다 켜도 설정은 남습니다.

자주 묻는 것

채팅 오버레이에 아무것도 안 보여요.

봇이 켜져 있는지, URL을 정확히 붙였는지 보세요. 봇을 켠 직후에는 예시 채팅이 잠깐 보였다가 실제 채팅이 오면 바뀝니다. 브라우저 소스의 "소스가 보이지 않을 때 종료"는 꺼 두세요.

CSS를 넣었더니 글자가 흰색이 됐어요.

CSS를 넣으면 기본 상자 디자인이 빠지고 넣은 CSS가 색을 정합니다. 그 CSS에 글자색이 없으면 흰색입니다. 밝은 화면에 쓸 거면 CSS에 .message{color:#111}처럼 색을 넣거나, CSS를 지우고 기본 설정을 쓰세요.

신청곡이 대기열에만 쌓이고 재생이 안 돼요.

기능 창 신청곡 화면의 배지를 보세요. 플레이어 없음이면 1번 플레이어 URL이 OBS에 없거나 그 소스가 꺼져 있습니다. 봇을 다시 켠 뒤라면 저절로 틀지 않으니 [재생 시작]을 누르세요. 플레이어 창을 연 적이 있으면 나중에 연 곳에서만 재생되므로, OBS에서 틀려면 창을 닫거나 OBS 소스에서 [새로 고침]을 누르세요.

신청곡 소리가 방송에 안 나가요.

플레이어 소리는 PC 기본 출력으로 나갑니다. OBS의 데스크톱 오디오가 그 장치를 잡고 있는지 보세요. 브라우저 소스의 "OBS를 통해 오디오 제어"를 켰다면 소리가 오디오 믹서의 그 소스로 가니, 거기서 음소거·볼륨을 확인하세요.

TTS 소리가 방송에 안 나가요.

소리는 PC 기본 출력으로 나갑니다. OBS의 데스크톱 오디오가 그 장치를 잡고 있는지 보세요. 헤드셋만 잡고 있으면 방송에는 안 나갑니다.

TITS가 "연결 안 됨"이에요.

TITS가 켜져 있는지, TITS Connections 화면의 API가 Enabled ON인지, 포트가 아인 설정과 같은지(기본 42069) 보세요. 아인은 15초마다 다시 시도하니 고치면 곧 붙습니다.

후원하면 TITS도 던지고 후원 룰렛도 도나요?

둘 다 조건에 맞으면 둘 다 동작합니다. 알림 카드와 채팅 인사도 각자 설정을 따릅니다.
