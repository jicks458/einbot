후원 인사에 필요한 권한

후원 인사에는 "후원 조회" 권한이 필요합니다. 설치할 때 동의 화면의 항목을 모두 켠 채 [동의]했다면 이미 됐습니다.

빠지면 아인 창에 노란 띠가 뜹니다. 다시 로그인한 뒤 봇을 한 번 껐다 켭니다. 구독·선물 인사는 권한이 필요 없습니다.

치즈 후원 감사 인사

시청자가 치즈를 후원하면 봇이 바로 인사합니다. 익명 후원이면 이름 자리에 "익명의 후원자"가 들어갑니다.

설정 → 후원 인사에서 켜고 끄며 문구를 바꿉니다. 치환자는 {이름} {호칭} {금액} {메시지}입니다. {메시지}는 문구 끝에 두세요. 말이 없으면 빈칸이 됩니다.

후원 룰렛을 켜 두었고 금액이 룰렛 규칙에 맞으면, 감사 인사 대신 룰렛 결과가 나갑니다(후원 룰렛).

구독 감사 인사

구독 인사는 채팅에 구독 메시지가 올라올 때만 나갑니다. 시청자가 구독·갱신 뒤 "기념 메시지를 남기시겠습니까?"에서 예를 누른 경우입니다. 조용히 구독·갱신했거나 방송 밖에서 갱신하면 인사도 없습니다.

선물받아 시작된 구독에는 인사하지 않습니다. 기본 문구는 1티어면 "3개월 구독", 2티어부터는 "3개월 2티어 구독"처럼 티어를 붙입니다.

설정 → 구독·선물 인사의 스위치 하나로 구독 인사와 선물 인사가 함께 켜지고 꺼집니다. 문구를 비워 두면 기본 문구가 나갑니다. 치환자는 {이름} {호칭} {개월} {티어표시} {티어번호} {티어}이고, 뜻은 치환자 한눈에에 있습니다.

구독권 선물 감사 인사

구독권을 선물하면 선물한 분께 인사합니다. 방송 중 채팅이 연결돼 있을 때, 봇을 켠 뒤 들어온 선물에만 인사합니다. 한 사람이 여러 장을 선물하면 한 번에 인사합니다.

문구는 같은 화면의 "선물한 분께 인사 문구"에서 바꿉니다. {개수}는 선물한 구독권 개수입니다.

팔로우 감사 인사

방송 중에 새로 팔로우한 분께 채팅으로 바로 인사합니다. 처음에는 꺼져 있습니다.

별빛여우님이 팔로우했습니다

초코우유 봇 💚 별빛여우 치수, 팔로우 감사합니다!

준비: 봇 계정을 채널 관리자로 지정

  1. 봇 계정이 없다면 설정 → 봇 계정에서 부계정으로 로그인합니다(봇 이름 정하기).
  2. 치지직 스튜디오 → 채널/권한 관리 → 권한 관리를 엽니다.
  3. 봇 계정의 닉네임(또는 UID)을 넣고, 역할을 "채널 관리자"로 고른 뒤 [추가]를 누릅니다.

봇 계정이 이미 목록에 있으면 그 줄의 역할만 "채널 관리자"로 바꿉니다. 팔로워 목록은 채널 관리자만 볼 수 있어서 이 준비가 필요합니다. 지정하면 1분 안에 아인이 알아챕니다.

채널 관리자는 방송 제목 변경 같은 권한도 함께 갖습니다. 본인의 부계정에만 주세요.

켜기

설정 → 팔로우 인사에서 "새로 팔로우하면 자동으로 인사"를 켜고 [저장]합니다. 치환자는 {이름} {호칭} {인원}(이번에 팔로우한 사람 수)입니다.

방송 중에만, 같은 분께 한 번만 인사합니다. 방송 화면 카드와 알림 소리는 기능 창 → 알림 오버레이에서 따로 켭니다. 둘 다 처음에는 꺼져 있습니다.

안 나갈 때 확인할 것

후원 인사가 안 나가요

아인 창에 "후원 조회 권한이 빠져 후원 인사가 나가지 않습니다" 띠가 있는지 봅니다. 있으면 다시 로그인한 뒤 봇을 껐다 켭니다. 띠가 없으면 설정 → 후원 인사의 "후원이 오면 자동으로 인사"가 켜져 있는지 봅니다. 후원 룰렛이 도는 후원에는 감사 인사 대신 룰렛 결과가 나갑니다.

구독 인사만 안 나가요

구독 인사는 시청자가 채팅에 구독 메시지를 올렸을 때만 나갑니다. 메시지가 올라왔는데도 조용하면 설정 → 구독·선물 인사가 켜져 있는지 봅니다.

팔로우 인사가 안 나가요

처음에는 꺼져 있습니다. 설정 → 팔로우 인사에서 켰는지, 방송 중인지 봅니다. 아인 창에 "봇 계정을 채널 관리자로 지정해야 합니다" 띠가 있으면 봇 계정을 채널 관리자로 지정합니다. 팔로우를 취소했다 다시 한 분께는 다시 인사하지 않습니다.
